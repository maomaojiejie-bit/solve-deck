# 「免费的 AI」怎么办

先分清两件事，它们不是一个问题：

| 说法 | 真实含义 | 我们要不要做 |
|---|---|---|
| **不要钱、也不用配置** | 就是现在这套**规则解析**（纯本地正则 + 关键词，零请求、零费用、离线可用） | ✅ 已经是默认路径 |
| **不要钱，但要注册拿 key** | 各家给的免费额度（GLM-4V-Flash / Gemini 免费层 / 百炼新用户额度） | ✅ 加进预设，标「免费额度」 |
| 完全不注册还能看图的通用模型 | 不存在稳定、合规、可长期用的端点 | ❌ 不碰 |

## 1. 默认路径已经是「免费」的

`#/solve` 不配 key 时走规则解析：33 条关键词规则 + 单位换挡，覆盖 12 类常见题干，**一个网络请求都不发**。这条对评委最重要——评委不会为了点开一个作品去申请 API key。

要做的只有一件事：**把它说清楚**。`#/solve` 顶部加一句：

> 不需要任何配置：直接贴题干文字，规则解析能认出 12 类常见题型。想让 AI 读图，再往下配一个免费额度的 key。

## 2. 加三条「免费额度」预设（仍需用户自己注册）

`presets.ts` 增加 `free: boolean` 字段，UI 用「免费额度」小徽章标出。文案只写搜索词，**不写网址**（撞 p0 门禁，也没必要）：

| id | label | model | vision | 备注文案 |
|---|---|---|---|---|
| `zhipu-glm4v-flash` | 智谱 GLM-4V-Flash（标称免费） | `glm-4v-flash` | ✅ | 「官方标称免费，额度与限流以控制台为准」 |
| `gemini-flash` | Google Gemini Flash（免费层） | `gemini-2.0-flash` | ✅ | 「免费层有速率限制，适合个人试用」 |
| `dashscope-qwen-vl` | 通义千问 VL（新用户免费额度） | `qwen-vl-max` | ✅ | 「新用户每模型有免费额度，用完按量计费」 |

设置抽屉里三行说明，写成可搜索的中文短语：

```
智谱：搜索「智谱开放平台 API Key」
Gemini：搜索「Google AI Studio API key」
百炼：搜索「阿里云百炼 API-KEY 管理」
```

**不要**替用户申请、不要内置任何 key、不要做「官方代理」——那会把隐私与合规问题全招到自己身上。

## 3. 明确不做的两条

- **浏览器内置 Prompt API**（Chrome `LanguageModel`）：要 138+ 且多半还得开 flag，评委机器上大概率没有。做了等于给自己埋一个「点了没反应」。
- **浏览器本地视觉模型**（transformers.js / ONNX）：首次要下 100MB+，静态站首屏代价太大，还会引依赖。

## 4. 门禁与文案的一致性

- `presets.ts` 的 `free` 只是**标签**，不是承诺。UI 文案必须带「以控制台为准」，不许写「永久免费」。
- `check:ai` 加一条：预设里每个 `vision: true` 的项，其 `label` 必须含「VL / Vision / Flash / 4V」之一（防止把纯文本模型标成能读图，用户贴图后白等）。
- 报告里如实写一句：「免费额度需要用户自己注册；不配置时用规则解析，功能不受影响，只是不能读图。」
