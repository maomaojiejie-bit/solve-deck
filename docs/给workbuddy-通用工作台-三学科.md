# 通用工作台·三学科版（静力 / 电路 / 数字）

## 一句话架构

**一个 `#/lab` 页面，三个 tab，共用同一套壳（节点表 + 元件表 + 结果面板 + 只读画布），三个求解器做成插件。**

```
                ┌───────────── 共用壳 ─────────────┐
                │ 元件库 │ 表格编辑 │ 自动出图 │ 结果面板 │ 校核矩阵 │
                └───────┬─────────┬─────────┬──────┘
                        │         │         │
                 静力求解器    电路求解器   数字求值器
                 (刚度法)      (MNA)       (拓扑序 + 时钟)
```

**别做三个独立工作台。** 壳共用、只换三样东西：元件库、求解器、校核项。

## 0. 三个「节点」不是同一个概念（最容易做错的地方）

| 学科 | 节点是什么 | 自由度 |
|---|---|---|
| 静力 | 结构上的点（可承力、可转动） | 每节点 `(u, v, θ)` |
| 电路 | **等电位点**（导线连起来的整体） | 每节点 1 个电位 `v`，另加支路电流变量 |
| 数字 | 一根信号线 | 1 个布尔值 / 1 个时钟沿状态 |

壳只能统一「表格长什么样」，**不能统一底层语义**。每档各自定义自己的 `NodeSpec`，别强行抽象成同一个接口——这是 Three 个求解器里唯一会让人写出假抽象的地方。

## 2. 电路（W8b）

### 元件库（DC 工作点 + 线性）

| 元件 | 说明 | 是否新写 |
|---|---|---|

| `V` / `I` | 独立电压源 / 电流源 | 已有 |
| `E` / `G` | VCVS / VCCS | 已有（A3 的受控源） |

### 求解与校核

- 装配：节点电位 + 独立/受控电压源的支路电流 → `A x = b`；`GND` 接地（把该行/列划去，不用大数法）；
- 校核项：①每个节点 KCL 残差 `<1e-12 A` ②电源支路功率守恒 `ΣP=0`（`|ΣVI| < 1e-9`）③受控源控制关系回代 ④参考节点唯一。

## 3. 数字（W8c）

元件库：`INPUT` / `OUTPUT` / `AND` / `OR` / `NOT` / `NAND` / `NOR` / `XOR` / `DFF`。

- 组合：拓扑排序后求值；有环（无触发器）→ 报「组合环，无法求值」；
- 时序：`CLK` + `DFF`（上升沿采样），跑 N 个时钟周期输出波形；
- 校核：①所有输入组合遍历（≤ 6 个输入，64 行）与真值表一致 ②`DFF` 保持/翻转两拍正确 ③输出没被悬空（每个 INPUT 都驱动了东西）。

### 三组标准答案

| 网络 | 期望 |
|---|---|
| `F = A·B + C'` | 真值表 `Σm(0,2,4,6,7)`（与 D1 一致） |
| 全加器 | `S=Σm(1,2,4,7)`，`Cout=Σm(3,5,6,7)` |
| 2 位计数器（2×DFF + XOR） | 4 拍波形 `00→01→10→11→00` |

## 4. 门禁 `scripts/check-lab.mjs`（最强的一条：对拍既有 28 型）

1. **同模两种入口必须同解**（这是整个工作台可信度的根）：
   - 用静力 builder 搭 `L=4, P=20@2` 的简支梁 → 与 `M3` 快照 `R/M` 逐位一致；
   - 用静力 builder 搭 `L=2, P=10@1` 的悬臂 → 与 `M3-cantilever` 逐位一致；
   - 用电路 builder 搭 A3 的 π 模型网表 → 与 `A3` 快照 `Av/Ri/Ro` 逐位一致；
   - 用电路 builder 搭 A6 反相运放 → 与 `A6` 逐位一致（容差 1e-4）；
   - 用数字 builder 搭 `F=A·B+C'` → 与 `D1` 真值表一致。
2. 上面的五组静力 + 五组电路 + 三组数字标准答案逐位。
3. 校核项全 PASS（KCL / 功率守恒 / ΣF=0 / ΣM=0 / ‖Ku−F‖ / 真值表）。
4. **该拒的必须拒**：静力机构、组合环、多个 GND、缺 GND、悬空输出 → 各有断言，文案要中文说人话。
5. 元件表/节点表的引用完整性：`element.i` 必须存在于 `nodes`，删除节点时引用它的元件一并报错。

变异三条：① 把刚度矩阵 `12EI/L³` 改错 → 第 1、2 条 fail；② 把 MNA 的 `GND` 去掉 → KCL 断言 fail；③ 把数字拓扑排序的环检测删掉 → 第 4 条 fail。

## 5. 分期（合计约 4 天，建议在提交之后）

| 期 | 内容 | 工时 |
|---|---|---|
| W8a | 静力求解器 + 五组答案 + `check:frame` | 1 天 |
| W8b | 电路求解器（复用 `solveMNA`）+ 五组答案 + 对拍 A3/A6 | 1 天 |
| W8c | 数字求值器 + 三组答案 + 对拍 D1 | 0.5 天 |
| W8d | `#/lab` 壳统一（三 tab、共享表格/画布/结果面板） | 1.5 天 |

**W8a–W8c 都先不做 UI**：用固定 JSON 跑通求解器与门禁，再统一做壳。这样任何一档算错了，都还来得及砍掉那一档而不影响另外两档。

## 6. 不做

- 不做自由拖拽画布、3D、动力、非线性（BJT 工作点 / 二极管）、交流相量、瞬态。
- 不做「AI 生成电路/结构」——AI 只许选模板与填参数，**结构由人搭**。
- 不把三档硬抽象成同一个 `Solver` 接口（节点语义不同，抽象必假）。

## 7. 与已有 28 型的关系

工作台不是替代 28 型，而是它的「第二条入口」：

- 28 型 = **精修样板间**（有讲解、有双图、有六项校核、有 PDF）；
- `#/lab` = **自由建模**（能搭出超静定的连续梁、任意门电路），但没有逐步讲解。

两条入口必须同解（§4 第 1 条），这既是最强的校验，也是作品最硬的一句话：
**「同一个模型，无论是点例题还是自己搭，算出来是同一个数。」**
