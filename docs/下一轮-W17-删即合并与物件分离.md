## 1. 任务 A：删除即合并（dc 拓扑修复）

`deleteEdge` / `deleteDevice` / `deleteMember` 之后统一跑一次 `healTopology(graph, removed)`：

| 被删的东西 | 处理 |
|---|---|
| **串联器件/杆件**（它两端网络 A、B 之间除它以外没有别的路径） | **合并 A、B**：两条断头变一条，节点 id 保留 A，B 的成员并入 A |
| **一端接信号网、一端接 gnd / 电源轨的器件**（负载型：Rl、Re、Rss、旁路电容） | **不合并**（合并就等于把信号网短到地）。只发开该支路，另一端仍挂着，`appliedRules` 记「已删除负载 Rl：输出支路开路」 |
| **两端都被别的路径连着的并联器件**（Rc 这类与 AC 地并联的） | 不合并，删完图仍连通，照常求解 |
| **杆件**（力学族 member） | 节点不合并（节点是自由度载体，合并会改结构），只删杆 + 记 `appliedRules` |

三条**硬规则**，任何一条不满足就**不合并**，退回现在的行为（断头 + 人话提示）：

1. `A !== B`；
2. 合并后 **gnd 不与其它网络相撞**（`{gnd}` 与任何非 gnd 网合并 → 拒绝）；
3. 合并后 **不出现电压源被判短**（同 `vSourceLoop` 判据）。

合并必须**可撤销**：`undo` 的入场快照要含合并后的图，撤销后回到「删之前」的连通状态（不是「删了但没合并」的中间态）。

### 验收（这一条是关键，别用"看着对"）

- A3 默认骨架删 `Rs` → `params` 里 `Rs = 0`（不是 1000），`appliedRules` 记「已删除器件「Rs」：串联在信号链上，两端合并（基极直连源）」；
- 同一张图用 `netSolve` 现算，`Av` 与「`Rs=0` 的等价图」逐位相等（≤1e-12）。参考值：`gm=0.03846153846153846`、`Rc=2000`、`Rl=10000`、`ro=100000` → `Rc∥Rl∥ro = 1639.34…`，`Av ≈ -63.05`；
- 删 `Rl` → **不合并**，`Av` 仍按 `Rc∥ro` 算，`appliedRules` 记「输出支路开路」；
- 删 `Rc` → 现状不变（走「Rc→∞ 挂交流地」那条既有规则），别被 A 覆盖掉；
- 删 `gnd` → 仍 U 档拒答，一个数字都不出。

## 3. 任务 C：物件与杆分开，各选各的

力学族现在把东西摊在一个「画布器件」列表里，节点/支座/载荷和杆件混着眼花；画布上点线还是点节点也不明确。改成**左栏两组、选中互斥**：

> 现状别推倒重来：左栏其实已经有「画布器件」和「杆件 / 梁段」两个小标题（`lab-06-members.png` 可见），缺的是三件——① 支座、载荷被叫作「器件」，词不对；② 两组都**不能在画布上点选**，只能点行；③ 杆行只有「删」，改不了 `A/I/E`。本轮是把这三件补齐 + 加选中条，不是从零分组。


- **物件**（`nodes`）：节点、支座（固定铰/可动铰/固定端）、集中力/均布/力偶。每行显示 `A · 固定铰`。
- **杆**（`members`）：每行显示 `AB · 杆件`，可改 `A`（截面积）/`I`/`E`，可删。
- **电路族沿用**「器件 / 导线」两组（已经分开，只对齐交互）：器件行含数值、旋转、语义；导线行只含 id 与删。
- 画布命中：点节点圆点选物件、点杆线选杆（杆的命中带 6px 容差，和导线一致）；**同一时刻只有一个选择**，底部选中条写清类型：
  - 「已选：物件 A · 固定铰 [改类型] [删]」
  - 「已选：杆 AB [改 A/I/E] [删]」
- `Delete` 按当前选择分派（物件 → 删节点，但**连带杆必须一起删**并给确认；杆 → 删杆，走 `m = 2j−3` 判据）。
- `Tab` 顺序：物件组 → 杆组 → 导线组，每组内部按画布顺序。

### 验收

- S5 三角桁架：左栏出现「物件 3（A/B/C + 两个支座 + 一个载荷）」与「杆 3（AC/AB/BC）」两组，行数分别为 3 与 3；
- 点画布上的 AC 杆 → 选中条是「杆 AC」，`Delete` 只删这根杆，判据出「m = 2j−3 = 3，少一根」；
- 点节点 C → 选中条是「物件 C」，`Delete` 弹「删节点 C 会连带删掉 AC、BC 两根杆」确认；
- A3：左栏两组仍是「器件 5 / 导线 11」，点导线选中、`Delete` 只删这条线（现状不回退）。
