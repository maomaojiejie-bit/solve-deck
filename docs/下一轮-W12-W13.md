### 任务 B · 小信号快速输入（折叠块）

两模式，同一份数据两个方向：

```
Ic / β / VA  →  gm = Ic/Vt,  rπ = β/gm,  ro = VA/Ic
gm / ro / β  →  Ic = gm·Vt,  VA = ro·Ic
```

- 推导出来的项打标 **「推得」**，并写 `由 Ic=1 mA、β=100 推得`；
- **手改过的项不再被覆盖**（改 `gm` 就把 `Ic` 变成「推得」，改 `Ic` 反过来）；
- 常驻一致性提示：`gm 与 Ic 不一致（相差 3.8%）`，点一下可回到一致；
- `Vt` 默认 26 mV、显示单位 mS / kΩ / MΩ；
- 同一个折叠块也放进 `#/solve`（同一个组件，不复制两套逻辑）。

## 批次二（W13，预计 1 天）：复合器件

见 `docs/给workbuddy-W13-复合器件.md`，要点只有四条：

1. `expandComposites(graph, defs)` 放在 `reduce()` **第一行**，所以 `picks.ts` 一行都不用改；
2. 端口就是内层某个节点（展开后内外同一电气节点），深度 ≤2，悬空端口只警告；
3. 四条硬闸门：缺 `modelSpec` → U、缺夹具 → U、内层夹带白名单外器件 → U、复合器件不计 semantic 正向分；
4. 分享必须自带 `defs`（否则别人打开会少一块）。

**最关键的断言：摊开前后 `params` 逐键相等（≤1e-12）** —— 证明"复合只是换个说法"，不是"换个算法"。
