# R3-4 · 智能选点与「一句话定条件」

> 用户原话（m04815）：「可以让用户自己选点，并且点必须很智能，同时可以让用户更简单来定条件」。
> 这一批做两件事：**点哪儿就有哪儿**、**一个动作落一个条件**。不改求解器、不改快照。

## 0. 现在到底卡在哪（我按代码核过，不是印象）

画布点击走 `src/core/lab/pointer.ts` 的 `wireClick(graph, session, hit)`，命中类型只有五种：

```ts
export type PointerHit =
  | { kind: 'pin'; key: string }
  | { kind: 'node'; key: string }
  | { kind: 'body'; nodeKind?: string }   // 器件本体
  | { kind: 'label' }
  | { kind: 'blank' };
```

三种行为：

| 点在哪 | 现在发生什么 | 用户想要的 |
|---|---|---|
| 引脚 / 结点 | 起线或收线（正常） | 一样，但**要能看清吸附到的是哪个引脚** |
| **器件/杆件本体** | 一句提示「本体不是接线端点」就完了 | **在这一点上落这个条件**（力、支座、切杆） |
| **空白处** | 静默取消连线 | **在这儿放一个结点** |
| 标签 | 提示「这是文本」 | 一样 |

所以「在这根杆的 1/3 处加一个 20 kN 向下的力」今天是 **3 步**：选中杆 → 点 `+ 集中力` → 在新的选中条里改 `t=0.50→0.33`、再点方向 `↓`。`t` 还是个数字输入框。

## 1. 智能选点：命中优先级 + 吸附

给 `PointerHit` 加两种（**新增，不动老的五种语义**）：

```ts
| { kind: 'member'; edgeId: string; t: number; dist: number }  // 杆体内部投影点
| { kind: 'blank'; x: number; y: number }                     // 世界坐标
```

**优先级（光标 12 逻辑单位内）**：`pin` > `junction(dot)` > `member 端点` > `member 内部` > `node` > `blank`。
同距离时**引脚优先**——端点属于器件，不许被杆身抢走；这条是硬规则，写进门禁。

**吸附规则**

- 杆内 `t` 吸附到 `0, 1/4, 1/3, 1/2, 2/3, 3/4, 1`：距刻度 ≤6 单位就取刻度值，否则自由 `t`（保留两位、开放区间 `(0,1)`，端点不能放跨内载荷）。
- 空白吸附 20 单位网格。
- 引脚吸附半径 12，`dot` 10（junction 比引脚小，避免抢）。

## 2. hover 必须先说清楚「点下去会发生什么」

点之前，光标旁一行小字 + 图上高亮候选（这是「很智能」的可见部分）：

| 光标位置 | 预览文案 | 图上高亮 |
|---|---|---|
| 引脚 | `吸附到 Q 基极 b` | 该引脚画实心环 |
| 杆内 | `MEMBER 上 t=0.25 加集中力 ↓` | 杆段加粗 + 在 t 处画刻度线 + 箭头 ghost |
| 空白（放结点模式） | `放一个结点（吸附到网格）` | 一个空圈 |
| 器件本体（电路） | `可选三个引脚：c / b / e` | 三个引脚同时亮 |
| 两个候选距离差 <3 | 追加 `Tab 切换候选` | 候选都画虚线环 |

## 3. 一步定条件（四种放置器）

顶部工具条从「先选东西再点按钮」改成**先选放置器，再在图上指**：

1. **集中力**：在杆上按下 → 箭头 ghost 跟手（拖动方向即受力方向；移动 <8 单位按「垂直向下」）→ 松手即落 `atMember{edgeId,t}` + `dir` + 当前 magnitude。
2. **均布**：在杆上按下并沿杆拖到另一点 → 落成 `q0/q1` 区间（`t0..t1`），ghost 画出整段箭头带。
3. **支座**：点结点 → 直接换支座类型，再点循环 `固定铰 → 可动铰 → 固定端 → 无`；点杆体中间 → 先切杆加点（复用 `addMember` 的分段逻辑）再加支座。
4. **结点**：点空白 → 放结点（吸附网格）。

电路侧同理：点引脚起线（不变），点器件本体不再是「一句提示」，而是**列出它的引脚名让用户点**（`n-rc:a / n-rc:b`），点了就起线。

## 4. 门禁 `scripts/check:pointer`

新 reducer 放 `src/core/lab/place.ts`，老 `wireClick` 一个字节都不改（它的不变式已被 `check:labshell`/`check:assemble` 钉住）。

1. 老行为不变：`blank` 仍取消连线、`body` 仍提示（同一条断言跑两遍 reducer 对比）
2. 12 单位内引脚优先于杆内（把杆中心放在引脚旁 5 单位，必须命中 pin）
3. `t` 吸附：点击距 1/4 刻度 5 单位 → `t` 必须恰为 `0.25`
4. 自由 `t` 保留两位且 ∈(0,1)（两端各试一次，必须被推回开区间）
5. 一步式集中力：`pointerdown` 在杆上 + `pointerup` 偏移 (0,+40) → 生成 `dir=0`（向下）+ `atMember{t}`，`appliedRules` 里出现「载荷落在 MEMBER t=…」
6. 电路本体点击必须列出 ≥3 个引脚名（禁止只回一句「不是端点」）
7. **变异**：把优先级改成 member 优先 → 门禁必须红；把吸附阈值 6 改成 0 → 门禁必须红
