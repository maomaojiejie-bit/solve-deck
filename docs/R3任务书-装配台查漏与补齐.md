# R3 任务书 · 装配台查漏与补齐（含原 R3 追加项）

> 老大报的三条我都复现了根因；这一份把「新查出来的漏洞」和「原 R3 追加项」并成一张表、四批活。
> 参考做法取自同类工具：EduBeam（结构分析，[Nodes & supports](https://www.edubeam.app/essentials/nodes-supports)）、Wokwi（[Interactive Diagram Editor](https://deepwiki.com/wokwi/wokwi-docs/3.2-interactive-diagram-editor)）、Falstad CircuitJS（[about](https://falstad.com/circuit/about.html)）。

## 0. 一页摘要

老大报的三条，根因分别是：

| 老大的说法 | 我的结论 |
|---|---|
| 新加入的移动铰没有可以连线的端点 | **真 bug**：支座被建成「和结点同坐标的第二个物件」，而力学族的锚点只取中心点 → 两个锚点重合，既点不中、也不知连哪个 |
| 箭头没有可以选择指向的位置 | **真缺口**：加载荷写死 `x: at.x, y: at.y, rot: 0`，只能落在（第一个）结点上、只能向下；跨内位置 `t` 根本没做 |
| 力学里不该有电学组件 | **真 bug**：`自定义模块` 那块没做族过滤，力学的「加入器件」是对的，`BUILTIN_COMPOSITES` 是全量渲染 |
| 三个问题的共同根因 | 「加东西」不认选中对象：`graph.nodes.find((n) => n.kind === 'dot')` 永远拿第一个结点 |

参照 EduBeam 的做法，正确模型不是「支座是独立物件」，而是 **结点自带支座属性 + 载荷挂在结点或杆件的位置 `t` 上**——它把「点在杆上」明确定义成一次选择：「连到结构（把杆切成两段）」还是「只放一个孤立结点」。

## 1. 参考做法（只取能落地的三条）

1. **EduBeam：结点是唯一的挂接点。** 支座是一组被约束的自由度（Dx/Dz/Ry），用符号选；「每个被约束的自由度都画一条反力」；结点在杆上落下去时会问「连到结构（切杆）」还是「孤立结点」。→ 我们的 A1/A2/A3 照这个做。
2. **EduBeam：稳定性是可见状态。** 支座不够时有 `Needs supports` 蓝 chip，支座数量够但约束不对（全平行 / 交于一点）给红色提示并画虚线的机构运动方向。→ 我们的 D1 照这个做。
3. **Wokwi / Falstad：引脚即端点，连线必须从引脚出发。** 器件有明确引脚，连线时高亮可连引脚、非法连接当场拒绝。→ 我们已有（`data-pin` + `pinAt`），A1 只是把支座也纳入同一套。

## 3. R3-A · 挂接与位置（必修，1.5 天）

**目标：让「点在哪儿」这件事有唯一答案。**

### A1 支座变成结点属性

- 数据：`CanvasNode` 加 `support?: { type: 'pin' | 'roller' | 'roller-x' | 'fixed'; angle?: number }`；旧的独立支座节点在 `graphFromSpec` 里折叠成属性（快照 35 份不许改，所以是「读入时折叠」）
- 画布：支座符号画在结点下方，**不单独可拖**；拖结点时支座跟着走（沿用 W18-E 的 follow 判据）
- 左栏「物件」里支座显示为结点子行：`A · 固定铰`，删支座 = 清掉该属性，不删结点
- 加支座：**必须作用在当前选中的结点**；没选中就给一句「先点一个结点，再加支座」

### A2 加东西一律认选中

- 加支座 / 加结点载荷 / 加杆件：`atNodeId` 用 `selection.kind === 'node' ? selection.id : null`，为空就拒绝并提示
- 三个按钮的 `disabled` 状态要显式（未选中时灰掉 + tooltip 说明）

### A3 载荷的位置与方向

- 两种载荷：**结点载荷**（挂在结点）与**跨内载荷**（挂在杆件的 `t ∈ (0,1)`，画布上显示 `t = 0.5`）
- 方向枚举：`↓ / ↑ / → / ← / 角度`（角度输入 0–360，箭头按角度旋转）
- 画布交互：从「加入器件」拖出箭头，落到杆上任意位置 → 自动算最近的 `t` 并吸附；落空则拒绝
- 归约：`t` 必须真的进 `reduce`（`a = t·L`），不是只画个箭头

**门禁 `check:attach`（六条 + 一条变异）**

1. 选中结点 B 后加支座 → 落在 B，不是第一个 dot
2. 支座附着后该结点只有**一个**可点锚点，且 `anchorsOfNode` 不再重复
3. 删结点 → 附着的支座与载荷一起消失
4. 加跨内载荷 `t = 0.5`（L=4, P=20）→ 归约 `a=2`，`Mmax=20 @x=2`（手算）
5. 载荷方向 `→`、`P=20` → 归约轴力分量 20 kN，`RA/RB` 竖向反力不变
6. 未选中任何对象时三个「加」按钮都是 disabled
7. 变异：把 `atNodeId` 改回 `find(n => n.kind === 'dot')` → 第 1 条红
