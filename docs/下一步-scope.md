## 这一轮做什么

`docs\给workbuddy-复杂题怎么办.md` 里的三件，只做这三件：

### 1. 新页 `#/scope`（六问判别器）

一页六问，每问两三个选项，实时给结论：

| 问 | 判定 |
|---|---|
| 支座反力能只靠静力平衡求出吗？ | 否 → 超静定 |
| 变形是线弹性小变形吗？ | 否 → 大变形/塑性 |
| 是平面问题吗？ | 否 → 空间力系 |
| 截面沿杆长是否不变？ | 否 → 变截面 |
| 全部是静力（不含惯性力、振动、冲击）吗？ | 否 → 动力 |
| 材料与几何关系是线性的吗？ | 否 → 非线性 |

结论三档，每档给一句人话 + 一个入口：

- **能直接算**：指向 28 型里对应的那几型（复用 wizard 的候选卡组件最省事）；
- **要先简化**：写清「改什么、改完与原题不等价」→ 给「按简化模型算」入口，并**强制挂 amber 黄条**；
- **不覆盖**：写清「这题需要什么方法」（位移法 / 力法 / 有限元 / 时程分析…）→ 只给「回首页看范围」与「贴题让我试试」两个出口，**不给任何数字**。

### 2. `#/solve` 硬拦截

题面里命中这 16 个词：超静定 / 刚架 / 连续梁 / 三弯矩 / 位移法 / 力法 / 空间力系 / 大变形 / 塑性 / 变截面 / 动力 / 振动 / 冲击 / 疲劳 / 断裂 / 热应力 —— **不进表单、不出参数**，直接出「不覆盖」卡（复用 §1 的第三档卡片），并保留题面文字让人可以改。

注意：拦截发生在**选题型之后、出参数之前**；已经手选了模板的路径不拦（人自己知道自己在简化）。
