## 1. 梁族：让「缺」变成「能填」（1 天）

现在 M3 / M3-cantilever / M4 / S3 的结论卡上，`stress` 与 `deflection` 一律显示「缺 b/h/E」。骨架不给、用户也没地方给 —— 这是评委一上手就会点到的空。

- `#/lab` 右栏「确认已知量」在**梁族骨架**下增加一组「截面」输入：`b`（mm）、`h`（mm）、`E`（GPa），写进 `graph.meta.section = { b, h, E }`（**不要**动 `templates/**`；现有 `picks` 已支持 `{src:'meta'}`，归约侧零改动）。
- 改动即重新 `interpretQuestion` → `stress` / `deflection` 由 `missing` 变 `present`；`δmax`、`σmax` 出现在结论卡，挠曲线与应力分布图随之出现。
- 单位与量纲：输入按 mm / GPa，内部按 m / Pa（与 `check:measures` 的量纲断言一致）。
- 门禁 `check:measures` 追加 3 条：①给截面后 M3 必须出 `stress` 且 `σmax` 与 `W=bh²/6` 手算一致（矩 100×200、P=20kN、跨中 M=20kN·m → `σ=30.00 MPa`）；②给截面后必须有 `deflection` 且 `δmax = PL³/(48EI) = 2.000 mm`；③**清空截面**后必须退回 `missing`（不许留着上次的数）。
