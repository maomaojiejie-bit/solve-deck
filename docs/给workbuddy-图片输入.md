# 题目带图怎么办（P7 的图片输入补章）

学生在照片里拍来的题，图里往往装着**一半以上的信息**：支座是铰还是辊轴、梁上有没有铰、桁架的杆怎么连、截面的形状。

所以图片不是「AI 的附加输入」，而是**题面的一部分**。按下面三条走，一条都不能省。

---

## A. 图当题面（零 AI，必做）

- 读题区支持三种进图：`Ctrl+V` 粘贴、拖放、点「选择图片」。
- 进图后出现「题目原图」卡片：缩略图（长边 ≤ 320px 显示）+ 「放大」（点开看原图，`object-contain`）+ 「删掉」。
- DOM 里给 `alt="题目原图"`，卡片上标明「仅作参照，不参与计算」。
- **无 key 时**：图片就是参照物，页面提示「未配置 AI：图片已作为题面参照，请对照填写参数」。这一句必须真的出现，不许静默吞掉。

## B. 有视觉模型时 AI 读图（可选，增强）

- 同一次 `/chat/completions` 请求里，`messages[0].content` 用数组形式塞 `{type:'image_url', image_url:{url: dataURL}}`，文字 prompt 里加一句：「图里的尺寸、支座类型、连接关系都要读，但**不许算结果**」。
- 模型不支持图（返回 400/`content must be text`）→ **如实降级**：保留已抽到的参数、保留图片卡片、显示「当前模型不支持读图，请对照图片填写参数」。不许把图片悄悄丢掉、不许清空表单。
- 一次最多 3 张图；第 4 张来的时候提示「最多 3 张」。

## C. 红线：图片永远不参与计算

- 图片只进两条路径：①显示；②发给你配置的服务商做「转写」。
- 不许写文件、不许进 `localStorage`、不许进 URL、不许进快照。
- 不许出现「看图直接给答案」的路径（这条等于把不变式 1 绕开了）。

---

## D. 必须做的预处理（浏览器端 canvas，约 80 行）

照片直接丢给模型，成功率会掉一半。进图后先过一遍：

1. **缩放**：长边 > 1600px 时等比缩到 1600（省 base64 体积，也够模型看）。
2. **压缩**：`canvas.toBlob('image/jpeg', 0.85)`，原图 > 4MB 时提到 0.7；压完仍 > 4MB 就提示「图片太大，请裁一下题目区域」。
3. **亮度/对比度**：像素级做一次直方图拉伸（取 2% 与 98% 分位当黑点白点），阴影/发灰的作业照能救回来。
4. 预处理只作用于「送模型的 dataURL」，**展示用的原图不处理**（用户要看到自己拍的那张）。

不做：去倾斜、透视校正、手写 OCR（这三件要么引依赖、要么误伤，收益不抵风险）。

## E. 门禁扩展（`check:ai`，再加 4 条）

1. **无 key + 贴图** → 页面出现「图片已作为题面参照」；且 `outcome.source === 'rule'`。
2. **mock 模型报不支持图**（返回 400）→ 出现「当前模型不支持读图」且**已抽到的参数还在**。
3. **图片不落盘**：跑完一次解析，`localStorage` 里只有 `sd.ai.v1` 四个字段，值里不含 `data:image`。
4. **3 张上限**：第 4 张被拒并提示。

变异一条：把「图片已作为题面参照」那句删掉 → 第 1 条必须 fail。
