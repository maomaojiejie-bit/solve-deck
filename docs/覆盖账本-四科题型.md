# 覆盖账本 · 四科题型与知识点

> 用途：回答老大那句「题型和知识点也要全面」。**把「全」拆成两种全**，一种能算、一种只能讲，都写清楚，不留想象空间。
> 基线：28 型（analog 7 / digital 6 / mechanics 8 / statics 7）+ 7 变体，`verify` = 0。
> 状态符号：**✅ 能算**（有 solver + 六项校核）/ **◐ 半算**（有 solver 但只覆盖一种情形）/ **○ 只讲**（本轮写纯讲解条目，不假装能算）

---

## 1. 判定口径（先立规矩，免得越做越大）

1. **「题型」的完整性看 solver**，不是看条目数量。每一型都要有：输入参数表 → 求解 → 六项校核 → 图。
2. **「知识点」的完整性看条目**。考纲上出现过、但求解器不做的（频率响应、稳定性判据、疲劳…），写成 **○ 只讲** 条目：定义 + 公式 + 图 + 坑，**不挂例题、不出现数字**。
3. 每个 ○ 条目页顶部一句话：「这条只讲，不算 —— 本版求解器不覆盖」。全站索引页顶部给「能算 28 / 只讲 N」的账。
4. **宁可标 ○，不许把概念题硬塞进 solver**（那会造出「看起来能算但其实在编」的东西，正是我们一直在防的）。

## 7. 三条不做（防止「全面」变成灾难）

1. **不为了凑数造 solver**：○ 条目一律无例题、无数字、无图（或只放线稿）。
2. **不在本轮扩到空间力系/动力学**：那是一个新求解域，不是加两个模板。
3. **不许把 ○ 条目做得像 ✅**：○ 条目页顶部固定一句话「这条只讲，不算」，索引页行右端标签 `只讲`（灰）与 `能算`（蓝）必须可区分。
