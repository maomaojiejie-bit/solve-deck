# W10-B：画布上点两下就连线 + 拖动 + 三个候选 + 参数覆盖

> 前置：W10-A 已验（verify=0，装配门禁 67 项含四条 UI 动作序列）。

## 0. 先说一个判断：点「引脚」，不要点「器件」

你说的是"点两个组件或节点"。力学可以照做（节点本来就是连接点），**电路不行**：

- 器件有多个端子（电阻 2 个、晶体管 3 个、运放 3 个）。点"器件"只能得出"接到器件中心"，那正是我们最早修掉的那个 bug —— R1/R2/Rc/Re 全汇到晶体管中心、看着像短路。
- 所以电路的交互定为：**点引脚 → 再点引脚**。为了让它一眼看得懂，每个引脚给一个半径 6 的可点圆点，鼠标移上去放大到 8 并变青。

一句话：**力学点节点，电路点引脚。** 不提供"点器件本体连线"。

## 任务 1 · 画布上点击连线（核心）

### 1.1 引脚可点

- 给每个器件的每个引脚渲染 `<circle r="6" data-pin="<nodeId>:<pinName>" class="pin-hit">`，`fill="transparent"`（看得见靠 hover 的描边）。
- 用**事件委托**，不要给每个圆点单独绑 handler：

```ts
onPointerDown={(e) => {
  const el = (e.target as Element).closest?.('[data-pin],[data-node]');
  ...
}}
```

- 命中后：该引脚画成青色实心 + `r=8`；同时从该点拉一条**橡皮筋**到光标（`pointermove` 更新，`dashed`、半透明青）。

### 1.2 第二次点击提交

- 落在**另一个**引脚上 → `mutate({ op:'addEdge', from:'n-vs:pp', to:'n-r:a' })`。
- 落在空白处 → 取消（清选中、清橡皮筋），不报错。
- 落在器件本体（不是引脚）→ 提示「请点器件的引脚端点」（toast 一次即可，别每次都弹）。

### 1.3 非法连线必须拒，且说清为什么

| 情况 | 提示 |
|---|---|
| 同一个引脚点两次 | 「两端是同一个点，接不了」 |
| 同一对引脚已连过 | 「这两个引脚之间已经有导线了」 |
| 两端同属一个器件（自环） | 「导线两端在这个器件的两个脚上，会短路」 |
| 跨族（电路引脚接力学节点） | 不可能发生，别写这个分支 |

拒绝时**不要**写进图、不要动 `dirty`。

### 1.4 力学族

同样的两次点击，但点的是节点（`data-node`）。提交 `addMember`。规则复用它已有的：`m ≤ 2j−3`、不得平行重复杆、不得零长（两端同一节点）。

### 1.5 门禁（`check:assemble` 补三条）

1. **真点击序列**：在 `#/lab/t/A3` 依次派发 `pointerdown` 到 `n-vs:p`、`n-r:a` → 图里多一条 edge，其 `points` 端点与该引脚世界坐标误差 < 0.6；`reduce()` 的 `params` 不变（新增导线不改参数）。
2. 非法三类各一条：同点两下、重复连线、自环 —— 都必须被拒且图不变。
3. 力学：在 S5 上点 `n-A` → `n-B` → 多一条杆，`m=3` 后可解。

## 任务 2 · 拖动节点（同一套指针层）

- `SpecGrid` 加 `editable?: boolean`（默认 `false`）与 `onNodeMove?(id, x, y)`。
- `pointerdown` 在 `data-node` 上（且不在 `data-pin` 上）→ 进入拖动：`setPointerCapture`、记 `start`。
- `pointermove`：吸附 8px 网格实时更新该节点 `x/y`（**只更新坐标，不重算导线**）。
- `pointerup`：写回 `CanvasGraph`，然后跑一次 `relayout(g)` 重算**全部** `edge.points`（拖动过程中不重算，避免抖动与性能问题）。
- 拖出画布边界 → 夹回。
- 双击节点 → 「自动整理」（对整张图跑 `relayout`）。
- `Esc` → 取消本次拖动（回到 `start`）。
- 门禁：拖动 `n-rc` 40px 后，① `reduce().params` **逐键不变**（坐标不是模型）；② 每条 `edge.points` 的首末点仍落在引脚上（误差 < 0.6）。

## 任务 3 · 生成 3 个候选

- lab 顶栏加「换三种接法」（力学：「换三种结构」），弹三张卡片：缩略图 240×140 + 标题 + 一句 why + 「载入画布 / 只看看」。
- 表：

| 题型 | 三候选 |
|---|---|
| A3 | CE / CB / CC |
| A5 | CS / CG / CD |
| A6 | 反相 / 同相 / 跟随 |
| A1 | 整流 / 稳压 / 限幅 |
| M3 | 简支 / 悬臂 / 带外伸 |
| S5 | 三角 / 双三角 / 加竖杆 |

- 用已有快照（`A3-CB`、`A3-CC`、`A5-CG`、`A5-CD`、`M3-cantilever`）当数据源；没有快照的三张（A6 跟随、A1 限幅、S5 双三角）先只做「why + 禁用态」，别硬造。
- 参数从当前图继承（`Rc=3300` → 三个候选都是 3300）；缺省值走候选自己的骨架默认。
- 门禁：有快照的候选逐位等于对应快照（≤1e-12）；`baseTemplateId` 正确；「只看看」不改 `dirty`。

## 顺手修两个 W10-A 的小毛病

1. `n-q`（晶体管）也渲染了「改器件种类」下拉，且显示成「电阻」——晶体管不在可改列表里，**不该出现在下拉里**（或显示为只读文本 `NPN`）。
