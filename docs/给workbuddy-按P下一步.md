## P6-B · 移动端：换成静态门禁，别再用 375 截图当证据

**为什么**：Edge headless 有最小窗口宽（约 500px），`--window-size=375,812` 是渲染 500 再裁到 375，**不是真视口**。我之前就是被这个骗过一次，你之前报的「375 无溢出」也一样不可信。

**做法**：`scripts/check-responsive.mjs`（零依赖，静态扫源码）：

1. 扫 `src/**/*.tsx|css` 里所有固定像素宽度：`w-[Npx]`、`min-w-[Npx]`、`style={{ width: N }}`、`width: Npx`；
2. 任何 `N > 320` 且不在白名单（`svg` 画布、`katex`、`canvas`、`Matrix`）→ fail，报「文件:行 元素宽 Npx 会撑破 375」；
3. 再加一条：`grid-cols-[4-9]` 若没有 `sm:`/`md:` 前缀 → fail（小屏会挤成一列）；
4. 接进 `build`（放在 `check:schematic` 之后）。

**验收**
- `PASS：N/N 项（响应式门禁）`。
- 报告里写一句「375 真视口无法在本机模拟（headless 最小宽 500），故改为静态门禁 + 已有 500 宽实测」，**不要**再截 375 图当证据。
