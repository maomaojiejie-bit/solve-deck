# 装配台 · 第二轮黑盒实测（交互 / 数值正确率 / UI）

> 测试对象：`http://localhost:5180`（dev 构建，含上一轮动画改动）
> 视口：Agent Window 1600×1000，CSS 1252–1530 之间（DPR 1.25）；浅色 / 深色都走过
> 手段：真实鼠标键盘操作（bsk 驱动 Edge），数值用 `mech_analyze` + `solve_math` 独立复算
> 结论分三组：**A 交互体验 / B 数值正确率 / C UI 设计**，每条给现象、复现、证据、建议

---

## 0. 先说结论

- **主求解器是可信的**：M3 简支梁两组参数（默认 a=2、a=1）的支座反力、|Q|max、|M|max 及其位置，与独立计算逐位一致；A3 的 gm / rπ / ro / Av / Ri / Ro（含「忽略 ro」那一列）也全部对得上。
- **错的是"最后一步的呈现"**：挠度极值取错了点、单位制只切了一半、体检表的公式标签与数值不匹配。
- **交互上最难受的是参数输入框**：不选中旧值、清空即写 0、无效值静默丢弃。
- **UI 上最影响可用性的是三栏断点**：CSS 宽 1252–1279 就塌成单栏，而这正是 1600 屏 @125% 的常见宽度。

# A. 交互体验

## A1. 参数框聚焦不选中旧值，输入是「拼接」而不是「替换」

- **现象**：M3 右栏「集中力 P」原本是 `0`，聚焦后直接敲 `2`、`0`，得到的是 **`020`**（数值 20，但显示成 020）。
- **危害**：如果原来是 `1`，想输 `20` 会得到 **`120`**——数值直接错一个数量级，且画布立刻按错值重算，用户很难第一时间发现。
- **复现**：清空 `P` → 聚焦 → 连敲两位数 → 观察输入框文本。
- **建议**：`onFocus={e => e.target.select()}`；失焦或回车时把 `Number` 重新写回 `value`，把 `020` 归一成 `20`。

## A2. 清空输入框＝立刻把 0 写进模型

- **现象**：把「集中力位置 a」全选删掉（中间态空串）时，模型立刻取 `a=0`：画布把 P 挪到左支座、实时读数变 `t=0.00`、参数行标红「超出 合法 0.1~3.9」。
- **危害**：`params` 里 `Number('') === 0`，用户只是想重打一个数，中间态已经被当真值用了；对 `L`、`P` 这类参数还会短暂出现 `P=0 / L=0` 的退化图。
- **证据**：`src/pages/Lab.tsx:3417` `onChange={(event) => onParamChange(param.key, Number(event.target.value))}`。
- **建议**：空串时不提交（保留上一个有效值，或存 `NaN` 并让下游跳过重算）。

## A3. 参数表里「图上还没有这个载荷」的项，输入被静默丢弃

- **现象**：M3 的 `q`（均布载荷）在画布上没有分布载荷时，输入 `5` 回车/失焦后值仍是 **0**，没有任何提示、没有禁用样式。
- **成因**：`picks.ts` 里 `q` 是 `missing: 0`，值从图里归约；参数表只是个镜像，写不进去。
- **建议**：这类项要么只读（灰掉 + 「画布上没有均布载荷」），要么给一行「先放一个均布」的引导按钮。

## A4. 同一批数值有两个入口，语义还不一样

- **现象**：右栏「参数表」改值 → 回到「未确认」，要点「确认」或「一键确认全部」才能解；同一批值下面的「参数实验场」改值 → **自动视为已确认**（其说明原文：「把这个项当作你已确认（已确认的标记不撤）」）。
- **危害**：同一个数，改的入口不同，能不能解、要不要再确认，结果不同；新手会以为机器状态不一致。
- **建议**：统一成「改值即回未确认」或「都自动确认」，并在两处给出同一句说明。

## A5. 结构改过之后，页头仍显示「已求解」和上一轮的校验横幅

- **现象**：删掉 END-B 后，页头仍并列着「已改动 · 已求解」「已从链接载入」「F · 解析解已验证」，下面还挂着绿色横幅「校验口径：6 通过 · 2 跳过」——而这 6 条通过是**删支座之前**那张图的结论。
- **危害**：结论与画布不同步，用户会以为当前这张图也过了 6 项校验。
- **建议**：结构一改就把校验横幅标灰/收起（例如「改动后需重算」，或直接隐藏并保留 chips 的「已求解」淡态）。

## A6. 零载荷仍在画布上画箭头

- **现象**：`P = 0 kN` 时，画布上照样画一根向下的箭头 + 标注 `P = 0 kN`，实时读数也写 `P = 0 kN · 落在构件 · t=0.25`。
- **建议**：`|P| < ε` 时不画箭头（或在读数里写「无集中力」）。

## A7. 同一页有两个「主题」开关

- **现象**：`button "切换到浅色模式"` 出现两次：一个在「全站导航」，一个在「讲解稿 分步推导与讲解」工具条右侧（就是那个齿轮）。
- **建议**：讲解稿那个去掉，或改成「跟随全站」。

## A8（做得好，留着）

- `Esc` 取消放置器有效（「q 20 kN/m 在杆上按一下」的提示条与输入框一起收起）。
- 删除节点有后果说明：`删节点 END-B 会连带删掉 构件 1 个构件、支座（可动铰）—— 确认要删吗？`，且删除后 toast 明说 **「已删除，可 Ctrl+Z 撤销」**，`Ctrl+Z` 确实能还原。
- 求解成功后页面自动滚到结果区（上一轮的「不跳结果」已修）。

# B. 数值计算正确率

## B1.【真错】挠度曲线是折线，δmax 取错点、偏小 14.5%

- **测试条件**：M3，`L=4 m`、`P=20 kN` 作用于 `a=1 m`、截面 `b=100 mm, h=200 mm`、`E=200 GPa`。
- **App 报**：`EI = 13333.3 kN·m²`（对）、`δmax = 1.19531 mm（向下）@ x = 2.5 m`。
- **独立复算**：`v(x) = P·b/(6LEI)·[(L/b)(x−a)³ + (L²−b²)x − x³]`，令 `dv/dx=0` 得 `x = 4−√5 = 1.76393 m`（`solve_math` 精确解），代入得 **`v = 1.3973 mm`**。
  - 校验一致性：同一公式在 `x=2.5` 给出 `1.19531 mm`——与 App 数字逐位相同，说明**积分本身是对的，错在"取极值"这一步**。
- **根因**：`src/core/lab/measures.ts:325-332` 只在 `points`（采样站）里找最大；而采样站由 `src/core/lab/frameSolve.ts:800-807` 生成——每个载荷分段只有 **起点 / 中点 / 端点** 三个点，本例全梁只有 `x = 0, 0.5, 1, 2.5, 4` 五个站。
- **连带**：绘图把五个站用直线连起来，于是「挠曲线」被画成三段折线（截图可见 x=1、x=2.5 两处折点），不是三次曲线。
- **建议**：
  1. 每段加密采样（≥12 点）后再取极值；
  2. 或在每段内解析求 `θ=0` 的位置（`θ` 是三次的导数，二分/求根很便宜），把 `δmax` 与位置按解析值报；
  3. 曲线用加密点绘制（或直接用解析式）。挠度是 M4/M5 两张骨架的主角，这个偏差会直接写到学生作业里。

## B2.【真错】单位制只切了一半：同页同时出现 `15 kN` 与 `15000 N`

- **测试条件**：M3（a=1, P=20），把「单位」从 `自动` 切到 `基本单位 SI` 后求解。
- **切了的**：结果表五行 —— `RA 15000 N`、`RB 5000 N`、`Qmax 15000 N`、`Qmin -5000 N`、`Mmax 15000 N·m`。
- **没切的**：
  - 同一条结果卡最下面的「结论」：`|M|max = 15.000 kN·m @ x=1.000 m`（还是 kN·m）；
  - 「内力」汇总行：`|M|max = 15 kN·m · |Q|max = 15 kN`；
  - 截面 / 挠度表：`W = 6.667e+5 mm³`、`|M|max 15 kN·m`、`EI 13333.3 kN·m²`、`δmax 1.19531 mm`；
  - **支座反力表干脆没有单位**：`Fx 0 · Fy 15 · Mz 0`。
- **危害**：同一屏同一个量两种写法，还要自己去判断哪个已换算；打印/交作业时容易抄错。
- **建议**：给「读数格式化」一个统一出口（`formatForce / formatMoment / formatLength`），所有表、卡、结论行都走它；反力表补单位。

## B3.【真错】A3 读数体检那行的公式标签与数值不匹配

- **现象**：「读数体检」里有一行 `增益上限 gm·(Rc∥RL∥ro)`，数值写 `-45.54`，右边又写 `|Av| ≤ 63.05`。
- **复算**：`gm = Ic/Vt = 1 mA / 26 mV = 38.4615 mS`；`Rc∥RL∥ro = 2000∥10000∥100000 = 1639.3 Ω`；`gm(Rc∥RL∥ro) = 63.05`。
  `-45.54 = 63.05 × rπ/(rπ+Rs) = 63.05 × 2600/3600` —— 也就是**已经含了 Rs 分压的整机增益**。
- **结论**：数值都对，但**标签错了**：`-45.54` 不是「增益上限 gm·(Rc∥RL∥ro)」，而是「含源内阻 Rs 的电压增益」。真正的上限是 63.05（右侧那列写对了）。
- **建议**：把这行改成 `gm·(Rc∥RL∥ro) = -63.05` + 单独一行 `含 Rs 分压 = -45.54`，或直接标 `Av(含 Rs)`。

## B4.【验证通过】主求解器（保留证据）

- M3 默认（`L=4, P=20@2`）：`RA=RB=10 kN`、`|M|max=20 kN·m @x=2`、`|Q|max=10 kN` ✓
- M3 `a=1`：`RA=15, RB=5`、`|M|max=15 kN·m @x=1`、`Q: +15 → −5` ✓（`mech_analyze` 独立复算逐位一致，8 项校核全过）
- A3：`gm=38.46 mS`、`rπ=2.6 kΩ`、`ro=100 kΩ`、`Av=-45.537`（含 Rs）、`Av(忽略 ro)=-46.296`、`Ri=2.6 kΩ`、`Ro=1.96 kΩ`、近似代价 `1.67%` ✓

# C. UI 设计

## C1. 三栏断点定在 1280，常见笔记本宽度恰好落在外面

- **实测**：CSS `innerWidth=1530` → `gridTemplateColumns: 316px 732px 320px`（三栏）；CSS `1252` → 单栏堆叠，画布被推到左栏（约 700px 高）之下。
- **换算**：1600×900 屏 @125% ≈ **1252**；1440×900 @125% ≈ 1152；1366×768 @125% ≈ 1093 —— 都进不去三栏。
- **后果**：装配时「左栏操作 / 画布 / 参数」三者看不全，来回滚动；这正是装配台最核心的动线。
- **建议**：三栏断点降到 1100 左右（316+320+画布最小 420 ≈ 1080 就够），或给左栏一个「折叠成图标条」的窄态。

## C2. 10px 小字 + `--color-faint`，对比度不到 4.5:1

- 浅色：`#857f72` on `#fbf8f1` ≈ **3.7:1**；深色：`#7c7566` on `#14120d` ≈ **4.1:1**。
- 而这些字正是关键语义：参数行右侧的 `归约 / 用户 / 题面 / 推得`、表下的「表格对照：本图种无图内高亮」、提示条等（`text-[10px] text-faint`）。
- **建议**：`faint` 只用于装饰；来源标签用 `muted`（≈6.6:1）并升到 11px。

## C3. ~~「这张图的量」副标题是病句~~（已撤回：误报）

- 原文实际是 `…应力与挠度会立刻出数。`（`src/ui/GraphMeasures.tsx:33`），语法正确。
- 我最初把「立**刻**出数」读成了「立刻**刻**出数」，是看图时的误读。此项撤回，不计入问题清单。

## C4. 状态 chip 与横幅重复播报同一件事

- 页头同时出现：`已改动 · 已求解` / `已从链接载入` / `F · 解析解已验证`，紧接着一条 `校验口径：6 通过 · 2 跳过`。
- **建议**：`F · 解析解已验证` 与校验横幅合并（chip 只留「已校验 · 6/8」并可点开自检）。

## C5. 参数表与参数实验场把同一批控件排了两遍

- 右栏一屏内 `L / a / P / q` 各出现两次（输入框 + 滑杆），整栏长度翻倍；且两者语义还不一致（见 A4）。

## C6. 构件行输入框只有 18px 宽

- `MEMBER 构件 A [1] I [1] E [1]`：三个数字框宽度约 18px，`1` 前后几乎没有内边距；浅色主题下边框对比度也低，很难看出这是可编辑控件。

## C7. 反力表没有单位（跨轮次仍存在）

- `END-A · 固定铰  Fx 0 · Fy 15 · Mz 0` —— 表头只写「全局坐标，y 向上；力偶逆时针为正」，没有单位；切 SI 后也不变（见 B2）。

# D. 建议的修复顺序

1. **B1 挠度极值**（会给出错答案，且是 M4/M5 主线）
2. **B2 单位统一出口**（同一屏两种写法，抄作业必错）
3. **A2 / A1 输入框语义**（空串≠0、聚焦全选）
4. **C1 三栏断点**（决定工作台能不能用）
5. **A3 / A4 参数入口语义统一**（无效项只读、确认规则一致）
6. **B3 体检表标签**、**C2 对比度**、**A5 结论与画布同步**、其余文案级（C3 已撤回为误报）
