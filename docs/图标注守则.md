# 图标注守则（W4）

坐标图与受力图上「标签压在线上」这一类问题，W1–W3 一共踩了五次。这一页只记结论，
不说过程；每条后面标了由哪道门禁守着 —— 没有门禁的规矩就是没写。

## 1. 标注压曲线：择向 + 文字描边

两件套缺一不可：

- **择向**：`placeMark()` 按位置就近往内侧放 —— 离底边近就朝上、离顶边近就朝下，
  贴边时改锚点（`start`/`end`）而不是移 mark 本身。**mark 的坐标永远等于解算值**，
  只让文字挪位，绝不为好看把点挪到弦上。
- **文字描边**：标签用 2px 底色描边（`paintOrder="stroke"` + 背景色 `stroke`），
  压在曲线或网格上也读得出来。只做择向不做描边，曲线穿字时仍然糊。

守门：`check:chart`（①marks 落曲线、②择向与贴边不裁剪）。
W3 的两处回归（M6 的 σ(θ) 采样不含极值点、M7 的欧拉曲线凸性）都落在这条上，
修法是把极值点**并进采样**，不是把标注点抬到极值。

## 2. 绝对值类标注必须 ≥ 0

`|M|max`、`|N|max`、`|Q|max` 这类带绝对值符号的标注，**写出来的数必须非负**：

- 文字的数值取 `Math.abs(...)`；
- 标注点的 y 取**该处的带符号值**（落在曲线上），两者分开算，不许互相借。

反例（已修）：M3 悬臂的 `|M|max` 直接把 `abs_max` 当 y，点在图上跑到顶边，
文字又印成 `-10.00`。现在 y 用带符号的 `mAtMax.value`，文字用 `Math.abs(Mmax)`。

守门：`check:chart`（以 `|` 开头的标注数值 ≥ 0）。

## 3. 图头只用英文 id

图头写 `principal-circle`、`internal`、`axial`，不写「主圆 principal-circle」。
中英重复会拼成 `mohr mohr`（W2 修过一次）；中文名放标题（`title`），
英文 id 留给图头与高亮引用。

## 4. 参数默认值以文档为准

`docs/短令-F力学.md` §2 是默认值的唯一来源。代码与文档不一致时**先改代码**；
改不动（文档写错了物理，或者这一波明令「不动求解结论」）就改文档，并在当轮报告里单列一条。

已按此改过的：M6 的默认值对齐 §2、S4 把一个 α 拆成拉角 α 与斜面倾角 β（文档错、代码对，
§3 待改成「两工况」）。

**仍不一致的四处**（W4 报告里列了清单）：M4 的支承类型、M5 的载荷类型、M7 的截面形状、
M8 的模型。这四处一改就要动求解结论，所以这一波只报不改。

## 5. 受力图：反力必须画箭头（W4 新增）

- 力箭头数 = **载荷力数 + 反力力数**；零反力分量不画（画个 0 会被读成「解出来一个 0」）。
- 反力偶画圆弧箭头（`momentArrow`），载荷偶只写标注 —— 同一点上往往已经有 2–3 个力箭头，
  再叠一个圆弧就是糊成一团（M8 右端）。
- 标签一律「名称 = 数值 单位」，数值用 solver 的符号（横向向上正、轴向向右正、力偶逆时针正）。
- 轴向力**尾在作用点、箭身朝外伸**：尖落在作用点上会被杆线和支座图形吃掉。
- 反力箭头与支座图元必须留空隙：力偶圆弧离轴 64px（固定端的墙线占到轴上方 ~25px）。

守门：`check:statics` ⑥（M1–M8 逐型数箭头、逐条回代 `solver.reactions`、零反力不许画）。
