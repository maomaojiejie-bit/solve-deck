## 1. 本轮已落地的改动：把「切换」这件事做成有过渡的

原来三处切换都是硬切：主题换色是一帧闪、点骨架卡到骨架出现之间什么都没有（慢的时候像卡住）、下拉菜单是凭空出现。这次按「动效要交代因果」的原则补了 5 处，并且全部尊重 `prefers-reduced-motion`。

| 场景 | 改了什么 | 机制 | 位置 |

## 3. 验证过、**不是**问题（避免误报）

- **深链 `#/lab/t/A3` 直接打开正常**。先前「点卡片没反应」的真因是 dev server 挂了 + 浏览器里跑的是旧 production build（`Failed to fetch dynamically imported module`）。hash 导航属于 same-document，不会 reload，只有真刷新才换 build。
- **结点落点准确**：`clientToWorld` 用 `getScreenCTM().inverse()`，受控实验点 screen(798,463) 得 world(900,300)，与提示条「吸附到网格 900, 300」一致。
- **空画布点求解会正常拒答**：红色横幅「本题不适用，不求解（画布还在，接着改就行）」+ 三条可操作建议，不是崩溃。
- **A3 全链路通**：确认 7 项 → 分步求解 → `Av = -45.5`，读数体检（4 项核对 · 1 项近似）/ 校验 / 结果卡都出得来，console 干净。
- **M3 全链路可重复**：换 session 重跑结果一致（`|M|max = 20 kN·m @ x = 2 m`、`|Q|max = 10 kN`），说明不是偶发。
