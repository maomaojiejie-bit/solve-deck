# 短令 · D 批次（P5 读题入口：把「我的题」变成「能算的题」）

现状：13 道题 + 参数滑杆已能改数字，但用户**不知道该选哪道题**，也没法把调好的题发给别人。
本批只做两件事，都要能点。

## D1 · 题目卡进 URL（30 分钟）

- 路由带查询串：`#/t/A3-CB?Rc=3300&beta=150&VA=100`，打开即还原组态与全部参数；
  数字模板用 `#/t/D1?bits=1010`。
- 参数变化时用 `history.replaceState` 同步 URL（不要 push，别把后退弄脏）。
- 结果页顶部加「复制链接」按钮，复制完整地址，`toast` 提示「链接已复制（含当前参数）」。
- 解析规则：只认 registry 里声明过的 key，非法/越界值一律回落到默认值并在 URL 里纠正；
  **不许因为参数非法而白屏**。
- 新增门禁 `check:url`：对 13 模板 + 4 变体各拼一条带非默认参数的 URL，
  断言「解析出的参数 === 期望值」且「解出的 Av/Ri/Ro 与直接传参一致」（1e-12），全过才绿。

## D2 · 选型向导（1 小时）

首页顶部加一个「我有道题 →」入口，三步问答，答完直接跳模板并预置参数：

1. 器件：BJT / MOS / 都不是
2. 输入接哪只脚：基极/栅极 · 发射极/源极（BJT/MOS 各自映射）
3. 输出取哪只脚 + 有无射极/源极电阻

映射表（写死即可，别做成推理引擎）：

| 器件 | 输入 | 输出 | 落点 |
| --- | --- | --- | --- |
| BJT | b | c | `#/t/A3`（CE） |
| BJT | e | c | `#/t/A3-CB` |
| BJT | b | e | `#/t/A3-CC` |
| MOS | g | d | `#/t/A5`（CS） |
| MOS | s | d | `#/t/A5-CG` |
| MOS | g | s | `#/t/A5-CD` |

- 落到结果页后，顶部横幅写「按你的回答，这是共基放大电路（CB）；如果不对，点这里换组态」。
- 答「都不是」→ 直接给一句「当前只支持 BJT/MOS 共射共基共集共源共栅共漏六种，其余模板见首页」，不硬跳。

## D3 · 反事实（可选，20 分钟，有余力再做）

只做两个开关，做完就停：
- A3-CB：把 `k` 里的 `RcL` 去掉 → 结果偏 1667 倍，红字标「漏乘并联项，差 1667×」；
- A3-CE：把 `ro` 当无穷 → 红字标「忽略 ro 差 x%」，同时并列两个答案。
