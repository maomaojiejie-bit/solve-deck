# W8：通用工作台（自己搭结构）——能做，但别做成拖拽画布

## 结论先说

你说的「拼接组件」方向是**对的**，而且它才是「复杂题」的真正答案——因为复杂题的本质不是参数多，而是**结构拓扑**超出了 28 型的固定模板。

但有一个关键替换：**不要做「自由拖拽画布」，要做「结构化建模表单 + 自动出图」，底下接一个标准 2D 框架刚度法求解器。**

理由：

- 自由画布 80% 的工作量在交互（命中检测、吸附、撤销、对齐、移动端），而评分表里「技术复杂度不计分」；
- 结构化表单 10 分钟能建一根连续梁，画布要拖 20 次；
- 刚度法一旦做成，**静定/超静定/连续梁/刚架/任意桁架一次全通**，这才是「解决复杂题」；
- 而且它能反过来变成「答案不是编的」的证明：静定特例必须与库里 M1–M4 逐位一致。

**成本真相：这个项目的成本不在写求解器（约 900 行），在校验。** 通用求解器最大的风险是「对某个复杂结构悄悄算错」，所以它必须带 4 组标准答案 + 与库对拍 + 残差断言，少一条都不许上。

---

## 1. 数据模型（这就是「组件」）

```ts
type Frame2D = {
  nodes: { id: string; x: number; y: number }[];          // 单位 m
  elements: {
    id: string;
    i: string; j: string;                                  // 端点节点
    kind: 'frame' | 'truss';                               // 刚接 / 铰接杆
    E: number; A: number; I: number;                        // GPa, m², m⁴
  }[];
  supports: { at: string; kind: 'fixed' | 'pin' | 'roller' | 'roller-x' }[];
  loads: (
    | { type: 'nodal'; at: string; fx: number; fy: number; mz: number }
    | { type: 'member-udl'; on: string; q: number }          // 沿杆均布（局部 y）
    | { type: 'member-point'; on: string; a: number; p: number } // 距 i 端 a 米
  )[];
  settings: { units: 'kN-m'; E: number };
};
```

「组件」= 节点 + 单元 + 支座 + 载荷，四张表就是四个积木盒。

## 2. 求解器（直接刚度法，`src/core/frame/`）

1. **单元刚度矩阵**
   - 2D 框架单元：局部 `6×6`（轴向 `EA/L`、弯曲 `12EI/L³, 6EI/L², 4EI/L, 2EI/L`），再乘坐标变换 `T`（`c=cosθ, s=sinθ`）；
   - 桁架单元：只保留轴向 `EA/L`，两端转动自由度释放（用大数法或自由度消去）。
2. **组装**：每个节点 3 个自由度 `(u, v, θ)`，`K` 为 `3n×3n` 稀疏（本工程规模小，直接稠密数组即可，n ≤ 40）。
3. **边界条件**：`fixed` 锁 3 个、`pin` 锁 `u,v`、`roller` 锁 `v`、`roller-x` 锁 `u`。用「行列划去」（不要用大数惩罚，会污染残差）。
4. **求解**：带主元选取的高斯消元（或 `LDLᵀ`），奇异 → 报「结构几何不稳定 / 机构」，**不许**返回近似值。
5. **回代**：节点位移 → 杆端力 `f = k·T·u` → 内力 `N(x), Q(x), M(x)`（含杆上载荷的叠加项）→ 支座反力 = 该节点所有杆端力之和。
6. **校核（必须实现且必须显示）**：`ΣFx=0`、`ΣFy=0`、`ΣMz=0` 的全域残差、每个节点残差、`‖Ku−F‖∞`。

## 3. UI（三块，不做拖拽）

- **左：建模表**。四张可编辑表（节点/单元/支座/载荷），行可增删，「＋加节点」「＋加单元（选 i,j）」「＋加支座」「＋加载荷」。每行有「定位」按钮 → 右侧图高亮该行。
- **中：只读画布**。由数据自动生成：节点用圆点、刚接用粗线、铰接杆用细线+两端小圆、支座用现有 `fixedSupport/pinSupport/rollerSupport` 图元、载荷用箭头/分布块。**允许拖节点改坐标**（这是唯一放开的手势，代码量小、体验收益大）；拖完写回表单。
- **右：结果面板**。反力表、杆端力表、`N/Q/M` 图（复用 `ChartSpec`，横轴用杆件局部 x）、变形图（放大系数可调）、六项校核。
- **模板起点**：进来先选「简支梁 / 悬臂梁 / 连续梁（两跨）/ 三角桁架 / 门式刚架」五个样例，一键填好表再改。

## 4. 必修的四组标准答案（我手算的，逐位对齐）

| 结构 | 参数 | 期望 |
|---|---|---|
| 简支梁 | `L=4, P=20@2` | `R_A=R_B=10 kN`，`Mmax=20 @x=2`（必须与库 `M3` 逐位一致） |
| 悬臂梁 | `L=2, P=10@1` | `R=10 kN`，`M_A=10 kN·m`，`M(0)=-10`（与库 M4-cantilever 一致） |
| 两跨连续梁（超静定 1 次） | `L1=L2=4, q=10 全跨` | `R_A=R_C=15 kN`，`R_B=50 kN`，`M_B=-20 kN·m` |
| 一端固定一端铰（超静定 1 次） | `L=4, q=10` | `R_A=25 kN`，`M_A=20 kN·m`，`R_B=15 kN` |
| 三角桁架 | `A(0,0)pin B(2,0)roller C(1,1)`，`P=10@C` | `N_AB=+5 kN`，`N_AC=N_BC=-7.071 kN`（与 `S5` 逐位一致） |

最后两条是「静态超静定」——它们能算出来，才说明刚度法真在工作，而不是在猜。

## 5. 门禁 `scripts/check-frame.mjs`

1. 五组标准答案逐位（1e-9）。
2. **静定特例对拍**：同一结构用 `frame` 与库 `mech_analyze` 各算一遍，`R/M` 相对误差 < 1e-9（≤3 条）。
3. 全域残差：`ΣF, ΣM` < 1e-9；`‖Ku−F‖∞` < 1e-9。
4. **机构必须被拒**：`roller-roller` 简支无侧向约束的刚架 → 必须报「几何不稳定」，不许给数。
5. 超静定能解：连续梁反力之和 = 总载荷（`1.25qL + 2×0.375qL = 2qL` ✓）。
6. `Q`/`M` 与 `EI v''` 的关系：`dM/dx = Q`（中心差分，<1e-6）。
7. 单元种类混用：一个 `frame` 梁 + 一根 `truss` 斜撑能算通。

变异三条：① 把 `12EI/L³` 写成 `6EI/L³` → 标准答案 1 必须 fail；② 删掉落支座约束 → 机构断言必须 fail；③ 把残差断言阈值放宽到 `1e-2` → 直接报「等于关闭校验」。

## 6. 分期（建议）

- **W8a（1 天）**：求解器 + 五组标准答案 + `check:frame` 通过（**先不做 UI**，用固定 JSON 跑）。
- **W8b（1 天）**：建模表 + 自动出图 + 拖节点改坐标 + 五个模板起点。
- **W8c（0.5 天）**：结果面板（反力/杆端力/三图/六项校核）+ 与 `#/scope` 打通（「能直接解」时给这个入口）。

## 7. 明确不做

- 不做自由拖拽画布（只拖节点）。
- 不做 3D、动力、塑性、屈曲（稳定另有 M7）、变截面、温度、支座沉降。
- 不做网格自动划分（这是框架，不是有限元实体）。
- 不让 AI 生成结构（AI 只许选模板与填参数；**结构由人搭**，这条不能破）。

## 8. 和学习曲线的取舍（我为什么还是建议做）

现在的 28 型是「精修样板间」，评委会觉得好但用不上自己的题。加上这个工作台后，产品才从「28 道例题」变成「一个能建模、能算、并且算错会告诉你错在哪的静力学工具」。

而它跟 `#/scope`、反例页是同一套品格：**能算就给真解，不能算就说不能算。**
