## C1 · 参数实验场（本批核心，约 90 分钟）

### 要做的交互

右栏「已知量」区（现在叫 `parsed_given`，只读）改成**可操作面板**：

- **模拟模板（A1–A7 + 4 个组态变体）**：每个参数一行，左边滑杆、右边数字输入框，带单位；
- **数字模板（D1–D6）**：输入向量改成**开关组**（A/B/C 三个 toggle，或按模板实际输入个数渲染），
  改一个 bit 立刻看到真值表/门级高亮/卡诺图三处同步；
- 每行末尾一个小的「默认」回位按钮；面板顶部一个「全部恢复默认」。

### 数据契约

在 `src/core/templates/registry.ts` 的模板定义里加参数描述（**不要让 UI 去猜范围**）：

```ts
export interface ParamSpec {
  key: string;          // 'Rc'
  label: string;        // 'Rc'
  unit?: string;        // 'Ω'
  kind: 'number' | 'bits';
  min?: number; max?: number; step?: number;   // number 用
  defaultValue: number | string | number[];    // 必须有
}
// 模板上加： params: ParamSpec[]
```

范围怎么定（按参数语义，别一律 default×5）：

| 参数 | 建议范围 |
| --- | --- |
| `Rc` / `Rd` / `Rs` / `Re` / `Rl` / `Rss` | 100 Ω – 100 kΩ（对数滑杆更好） |
| `beta` | 20 – 300，step 1 |
| `Ic` | 0.1 mA – 10 mA |
| `Vt` | 0.025 – 0.026 太细，改成「温度」旁路：先固定 0.026，不给滑杆 |
| `VA` | **20 – 200 V**（这一步很关键，见下面「教学点」） |
| `A`（A7 运放开环增益） | 1e3 – 1e6（对数） |
| `beta`（A7 反馈系数） | 0.001 – 0.1（对数） |
| `Vs` / `Vin` | 0.1 – 10 V |
| 数字模板的输入 | `bits`，值是 `[0/1,…]` |

### 联动与性能

1. 改动 → `debounce 80ms` → `solve(params)` → **重算 + 重绘 + 重新六项校验**，三处（步轨公式、画布、结果）同帧更新；
2. 一顿拖动必须 ≤ 16 ms/帧（13 个模板规模很小，`solve` 是纯函数，不要上 Worker）；
3. 拖动过程里**不要重置当前步骤**（用户停在第 3 步就留在第 3 步）；
4. 结果值变化时，数字用 `tabular-nums` 且**不许跳动换行**（宽度预留）。

### 越界与超域：不许静默

这是本批最重要的教学质量点。拖动到域外时必须**明说**，不能给一个看着对的数：

- A7 拖到 `T < 100`：右上角横幅转红，写「回路增益 T=xx < 100，超出深度负反馈近似域」，
  `Af` 只显示 `AfLoop`（MNA/回路值），**不显示深度负反馈近似值**；
- A3/A5 把 `VA` 拖到 20 V：结果里同时显示 `AvNoRo` 与「忽略 ro 会差 x%」，并提示「当前 VA 下该近似不成立」；
- 任何参数把器件推出放大区（A2/A4 的工作点判定）→ 结果区写「管子已进入饱和/截止区，线性模型不适用」；
- 校验条（六项）任一项失败 → 结论位显示「结论不可用」，不是黄色警告。

## C2 · 反事实沙盒（可选，约 30 分钟；C1 做完还有余力再做）

只做 **2 个**最有教学价值的「故意改错一步看下游」：

1. **A3/CB：`k` 漏乘 `RcL`** → `Av` 直接偏 1667 倍（= `Rc∥Rl`），弹条写
   「这一步漏乘并联项，误差正好等于该并联因子 —— 这就是为什么残差要按数量级读」；
2. **A3/CE：漏掉 `ro`** → 误差 = `RcL/ro`，与 C1 的提示互相对应。

交互：结果区一个「如果这一步写错会怎样？」按钮 → 出对比表（正确值 / 错值 / 倍数）+ 一句结论。
**不要**做成通用 mutation 引擎。
