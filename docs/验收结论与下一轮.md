### T2（中）容差是两处两个数，会各自漂移

现在 runner 里的门槛是硬编码的：

- `src/confidence/buildtime/a3Paths.ts:32` `const TOLERANCE = 1e-6;`
- `a5Paths.ts:24` `const TOLERANCE = 1e-6;`
- `a6Paths.ts:36` `lastError <= 1e-3 && rel <= 1e-3`
- `a7Paths.ts:47` `maxResidual <= 5e-3`（另有 `0.05` 的适域带）

而 registry 里声明的是同一组数字。**两处都能改，谁偷偷调松，另一处看不出来**——这正是 `VA=2000` 那次的同一个病：门槛和声明不是同一个来源。

做法（我试过，可跑通、变异测试 2/2 拦下，但按你的要求没留在代码里）：

1. 每个 Paths 模块导出常量，内部改用它：

```ts
/** 与 registry 里 symbolic-equiv 声明的 tolerance 必须一致（check:paths 会核对）。 */
export const A3_PATH_TOLERANCE = 1e-6;
const TOLERANCE = A3_PATH_TOLERANCE;
```

`A5_PATH_TOLERANCE = 1e-6`、`A6_PATH_TOLERANCE = 1e-3`、`A7_PATH_TOLERANCE = 5e-3`（外加 `A7_DOMAIN_BAND = 0.05`）。

2. `scripts/check-paths.mjs` 加一条：

```js
check('容差来源唯一：runner 用的门槛 == registry 声明的最松容差', () => {
  const loosest = (id) => Math.max(...getTemplate(id).paths.map((p) => p.tolerance ?? 1e-6));
  for (const [id, t] of [['A3', A3_PATH_TOLERANCE], ['A5', A5_PATH_TOLERANCE],
                         ['A6', A6_PATH_TOLERANCE], ['A7', A7_PATH_TOLERANCE]]) {
    must(t === loosest(id), `${id}: runner 用 ${t}，registry 声明 ${loosest(id)}——两处容差漂移了`);
    if (loosest(id) > 1e-6) {
      must(getTemplate(id).paths.some((p) => (p.tolerance ?? 1e-6) === loosest(id) && p.approximation?.trim()),
        `${id}: 容差放宽了但没写 approximation`);
    }
  }
});
```

3. 变异测试：把 `A3_PATH_TOLERANCE` 分别改成 `1e-3` 和 `1e-9`，`check:paths` 必须都变红并报「两处容差漂移」。
