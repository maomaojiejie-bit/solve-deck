## 这一波：三个图引擎 + M1–M4

范围与细节见 `docs\短令-F力学.md` 的 **§1（三个引擎）**、**§2 的 M1–M4**、**§5（界面）**。
要点复述一遍，免得你翻：

### 1. `ChartSpec`（坐标图：Q/M、轴力图、扭矩图）
`series.kind: 'line' | 'step' | 'area'`、`marks`（极值/断点标注）、`panels`（多联共享 x 轴）。
**硬要求：M3 的 Q 图与 M 图必须双联共享一条 x 轴，只让下面那张显示刻度。** 曲线是采样点直连，不拟合。

### 2. `MohrSpec`（莫尔圆）
这一波**只做引擎、不做模板**（M6 在 W2）。σ 轴与 τ 轴比例必须一致，画出来是圆不是椭圆。

### 3. 受力图
复用现有 schematic 引擎，只新增三种图元：`fixedSupport`（斜线阴影）、`pinSupport`（三角+铰）、
`rollerSupport`（三角+滚轮）。**不要另写一个渲染器。**

### 4. 四个模板上界面
M1 拉压 / M2 扭转 / M3 弯曲内力 / M4 弯曲应力：registry 条目（含 `ParamSpec`）、5 步叙事、
图、参数实验场、结果页六项校验（吃库的 `checks[]`）、结论位。
结论位规则：`σmax > [σ]` → 红字「超限 x%」；静不定 → 黄底「当前版本不解静不定」，**不给数字**。
图上每个数字都必须来自 solver 或库输出，不许画图时另估。

### 5. 新门禁 `check:chart`
坐标图不是 schematic，现有 S1–S16 管不到，补四条：
① `yDomain` 覆盖所有采样点；② `marks` 的 (x,y) 落在对应曲线上（1e-6 容差）；
③ `panels` 各子图的 `xDomain` 完全一致；④ M4 的 σ 分布里，中性轴位置与 `σ=0` 的交点一致（1e-6）。
照旧要做变异测试证明它会响（例如把 `yDomain` 收窄、把某个 mark 的 y 改 10%）。

### 6. 快照与截图
`src/examples/` 加 4 份（`M1 M2 M3 M4`），`check:p3` 自动覆盖；`docs/shots/` 出 `M1.png M2.png M3.png M4.png`。
