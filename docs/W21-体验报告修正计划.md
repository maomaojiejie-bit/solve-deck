### A1（报告 5.1）换结构后图与结果仍用旧模板

- 复现：`#/lab/t/M3` → 「换三种结构」→ 载入悬臂 → 分步求解 → 标题变 `M3-cantilever`、画布是悬臂，但主图/结果表仍是简支（RA=5/RB=5/Mmax=5）。
- 改法：`loadCandidate()` 里除了换 `pickId` 与 `graph`，**必须同时清空 `solution`/`generic`/`verdict` 并以新 graph 重建 `ui.preview` 与 `render_specs`**；禁止沿用上一份 `solverRef.current` 的闭包。给 `setStage('idle')` 一步。
- 验收：门禁 `check:coherence` 新增「换结构后三处同源」；重建后 `|M|max = 10 @ x=0`、`Fy=10 / Mz=10`。

### A2（报告 5.2 + 5.3）确认栏 / 归约预览 / 参数实验场三处三值

- 根因：确认栏显示的是**骨架默认值**，归约读的是**图上真实值**，两条链并存。
- 改法（裁决：**归约是唯一真相**）：
  1. 确认栏的值改读 `ui.preview.params`（与归约同一份），不再读骨架默认；
  2. 确认栏的输入框**可编辑并写回图**（`setLoadT` / `setLoadP` / `setSpan`），改完 `ui.preview` 跟着重算 —— 不再出现「勾了 a=2、算的是 a=3」；
  3. **确认变闸门**：未逐项确认时「分步求解」禁用 + 红字「还有 n 项没确认」，横幅不出现绿章。
- 验收：`check:paramlab` 加三条（改 `a` → 结果跟着变且确认栏同步；未确认 → 按钮禁用；确认后三处数值一致）。

### A3（报告 5.4）M5 算出挠度、同页写「不计算变形」

- 改法：`appliedRules` 的免责条**按能力分支**——`measures` 有 `deflection` 就不出这条；「填上后 σmax/δmax 立刻出数」这类承诺只在有 `stress`/`deflection` 的图上出现。
- 验收：`check:measures` 加「M5 页面文案不含『不计算变形』」；门禁扫 DOM 文本。

### A4（报告 5.5）六项表「结论」列被裁 + 口径三处不一致

- 改法：表格 `table-fixed`，`结论` 列固定 `72px` 且 `sticky`；「跳过」单独一行可点开（列出跳过项 id 与原因）；顶部徽标、横幅、页脚**只允许一个口径**（统一成「5 通过 · 1 跳过」并展开明细）。
- 验收：`check:coherence` 加「`skippedCount>0` 时不得出现『六项全部通过』字样」。

### A5（报告 5.10）裸浮点

- 改法：展示层统一格式化（4–5 位有效数字，`−10.000`、`−1.0000`），完整精度进「自检」抽屉；`validatedAt` / `contract v2.2` 移出主面板。
