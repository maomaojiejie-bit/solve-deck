## 1. 任务 A · `setDeviceValue`：任何器件都能改数值

### 数据
`CanvasNode` 加 `value?: number`（已有器件从 label 里解析出来的数写回这里，作为唯一真相）。

### op
```ts
| { op: 'setDeviceValue'; nodeId: string; value: number }
```
- 写 `node.value`，并按 kind 重写 `node.label`（`Rc 2.0k` / `C 10nF` / `Vs 5V`）。
- **`picks.ts` 优先读 `node.value`，读不到才回退 `valueFromLabel(label)`**。这样「题库骨架」与「手加器件」走同一条路：改数值不再依赖它在不在 pick 表里。
- 改完必须重跑 `reduce()`：数值变了 `params` 就变，`appliedRules` 不新增（这不是结构改动）。

### 界面
画布器件每一行：`[id] [label] [数值输入] [单位] [语义下拉] [删]`。
- 数值输入用 `type="number"` + 失焦提交（不要每次按键都 reduce）；范围为 `(0, 1e12)`，非法值红边不提交。
- 单位按 kind 固定：`res→Ω`、`cap→F`、`vsrc→V`、`isrc→A`、`res(力学用)→m`。**不要把单位做成可编辑**，那是给错的机会。
- 新增器件默认值要合理（`R=1k`、`C=1nF`、`V=5V`），加进来立刻可编辑。

### 门禁（写进 `check:assemble` ㉓，四条）
1. 手加一个 `R`，设成 `3.3k` → `reduce().params` 里出现对应值，`node.value===3300`，`label` 含 `3.3k`。
2. 把题库骨架里的 `Rc` 从 `2.0k` 改成 `4.7k` → `params.Rc===4700` 且 `Av` 随之变化（与手算 `-gm(Rc∥Rl∥ro)rπ/(Rs+rπ)` 比 ≤1e-9）。
3. 非法输入：设 `-1` 或 `abc` → 不提交、`node.value` 不变、输入框红边。
4. 变异：把 `picks.ts` 里"优先读 node.value"改回只读 label → ① 红（新器件读不到）。

## 2. 任务 B · `rotateDevice`：器件能转 90°

### op
```ts
| { op: 'rotateDevice'; nodeId: string; delta?: 90 | -90 }
```
- 写 `node.rot = (rot + delta + 360) % 360`，只允许 `0/90/180/270`。
- **旋转会改变引脚世界坐标**（`pinAt(kind, at, rot, pin)`），所以旋转后必须：
  1. 把所有以该器件为端点的导线**重新吸附**到新引脚坐标（端点原本落在旧引脚上的才改，用户手画的自由端点不动）；
  2. 跑一次 `relayout(graph)` 重算 `edge.points`；
  3. 再跑 `reduce()`——因为引脚变了，拓扑可能变（例如把二极管转 180° 等于反接），`params`/`problems` 都可能变。
- 进撤销栈（`rotateDevice` 算结构编辑）。

### 界面
- 器件行加一个 `⟳` 按钮（`title="旋转 90°（R）"`）；选中器件后按 `R` 也转。
- 旋转后画布要**立刻**看出方向变了（器件符号转、引线跟着转）。

### 门禁（`check:assemble` ㉔，四条）
1. 转 A3 的 `npn` 90° → `node.rot===90`，且 `graphFromSpec` 生成的三个引脚坐标与 `pinAt(kind,[x,y],90,pin)` 逐位相等。
2. 转完 `reduce()` 不崩、`problems` 有明确说明（或照常出数值），**不许静默出 NaN**。
3. 转二极管 180° → 反接被认出（`problems` 里出现"方向"或归约出的极性参数变号）。
4. 变异：旋转后不重新吸附导线端点 → ② 红（端点与引脚距离 > 0.6）。

## 3. 任务 C · `deleteEdge`：能删一条线

### op
```ts
| { op: 'deleteEdge'; edgeId: string }
```
- 从 `graph.edges` 移除该边；**之后必须做三件收尾**（复用 W14 那套）：
  1. `pruneJunctions`：不再有边穿过、也没有器件引脚的 dot 删掉；
  2. `retractFreeEnds`：被删边所属的 shared 长边端点回缩；
  3. 跑 `reduce()`：删线通常意味着**开路**，`reduce` 大概率给 `problems`——这时按三档规则走（U 档拒答 + 说清"哪两个引脚之间断了、补回哪根线能修"），**不许继续用旧数值出图**。

### 界面
- 画布上导线可点中：`hitTest` 用线宽 6px 的容差，命中后高亮（`stroke-width` 2.2 + cyan），底部显示「已选：导线 e-c-bus · [删]」。
- 选中后 `Delete`/`Backspace` 删；也可以从新增的「导线」列表逐条删（与器件列表同样的行式交互，力学族的「杆件/梁段」已经这么做）。
- 删前不弹确认（线可以撤销回来），但 toast 写「已删除导线，可 Ctrl+Z 撤销」。

### 门禁（`check:assemble` ㉕，四条）
1. 删 `e-c-bus` → `edges.length` 减 1，`reduce()` 返回 `problems` 非空（开路被认出），且**页面不渲染数值结果**。
2. `Ctrl+Z` → 边回来、`problems` 清空、数值结果恢复（逐字段相等）。
3. 删一条 shared 母线 → 端点回缩（右端点 x ≤ 最后一个附着器件引脚 x + 0.6）。
4. 变异：删边后不跑 `pruneJunctions` → ③ 红（留下孤立 dot）。
