# W12：画布处处能点、处处有名；小信号一次填完

> 两个诉求合成一批，因为它们都卡在同一个地方：**用户看不懂画布上的点是什么、也算不出要填的数**。

---

## 任务 A · 自由选点 + 每个点都有名字

### A1 现状为什么让人看不懂

画布上能连线的"点"有三种，但界面只承认一种：

| 点的类型 | 例子 | 现在能不能选 | 现在有没有名字 |
|---|---|---|---|
| 器件引脚 | `n-q:b`（基极） | ✅ 能点 | ❌ 只有 `b` |
| 汇流条 / 地轨锚点 | `d-cbus`、`d-e-gnd` | ❌ **点不到** | ❌ 只有 id |
| 器件中心 | `n-q` | 能拖，不能连 | ❌ |

所以左栏那个下拉里全是 `n-vs → r-1`、`d-cbus` 这种东西 —— 用户当然不知道 `vi`、`d-cbus` 是什么。

### A2 引脚加中文名（改一处，全局生效）

`src/render/symbols.ts` 的 `SymPin` 加一个可选字段：

```ts
export interface SymPin { id: string; x: number; y: number; label?: string }
```

新增一张按 `kind:pin` 查的表（查不到就回落到 pinId）：


用在三处：
1. 引脚 hover 时出 `<title>{中文名}</title>`（原生 tooltip，零依赖）；
2. 选中引脚时，画布上方浮一条小标签：`Q · 基极 b`；
3. 左栏「两次点击」的下拉，选项改成 **`A3 · Rc 端 A`** 这种可读格式，不再显示 `n-rc:a`。

### A3 汇流条 / 地轨也能选

W10-B 已经把 rail 端点注册成锚点了，现在把它们**也变成可点连接点**：

- `data-pin="rail:d-cbus"`，中文名写 `VCC 汇流条（交流地）`、`地轨`、`输出端 Vo`；
- 归属节点由已有的"最近节点"规则给出，UI 显示 `所属：集电极 C`；
- 这样"我想把 Rl 挂到输出端"就能直接点那条汇流条，而不是猜 `d-cbus`。

### A4 接不了的时候必须说明

点到不能连的位置（器件本体、文字、空白）：

| 位置 | 提示 |
|---|---|
| 器件本体 | 「这里不能接线，请点它的引脚（电阻有 A/B 两端）」 |
| 文字标签 | 「这是标注，不是电气点」 |
| 空白 | 静默取消（不弹） |

### A5 门禁

1. 每个可连引脚都有非空中文名（遍历 7 型的图，`PIN_LABEL` 缺一个就红）；
2. 点汇流条锚点 → 能连成导线，端点与该锚点坐标误差 < 0.6；
3. 点器件本体 → 出现「请点它的引脚」提示，且图不变；
4. 下拉选项文案里必须含中文（正则 `[\u4e00-\u9fa5]`），不许只剩 id。

## 任务 B · 小信号参数一次填完

### B1 痛点

A3/A5 要填 `beta, Ic, VA, Vt`，系统内部再算 `gm, rπ, ro`。但**很多题给的就是 `gm` 和 `ro`**，反过来要用户手算成 `Ic`/`VA` 才能填 —— 这就是"打起来很麻烦"。

### B2 加一个折叠块「小信号快速输入」

放在右侧「确认已知量」表上方，默认收起，标题：`小信号快速输入（填一侧，另一侧自动算出）`。两种模式，二选一：

**模式 1 · 从工作点推小信号**

| 输入 | 输出（只读，自动填） |
|---|---|
| `Ic` (mA)、`β`、`VA` (V) | `gm = Ic/Vt`、`rπ = β/gm`、`ro = VA/Ic` |

**模式 2 · 从小信号倒推**

| 输入 | 输出（只读，反填） |
|---|---|
| `gm` (mS)、`ro` (kΩ)、`β` | `Ic = gm·Vt`、`VA = ro·Ic` |

- `Vt` 默认 26 mV（跟随参数表里的 `Vt`）。
- 点「写入参数表」后，被写入的项来源标 **「推得」**（区别于「骨架」「题面」「手改」）。
- **一旦用户手改某一项，那一项变「手改」，后续再点写入不覆盖它**（只补还没手改的）。
- 常驻一行一致性提示：`gm 与 Ic 相差 2.1%，Vt=26mV 时 gm=Ic/Vt`（差 <0.5% 不显示）。

### B3 同一组件也放进 `#/solve`

`#/solve` 的参数表单里，A3/A5/A7 也挂这个折叠块 —— 从题面抄到 `gm=1mS` 时不必自己换成 `Ic=38.5µA`。

### B4 门禁

1. 模式 1：`Ic=1mA, β=100, VA=100, Vt=0.026` → `gm=0.0384615 S`、`rπ=2600 Ω`、`ro=100000 Ω`（必须与 A3 快照的 `parsed_given` 逐位一致）。
2. 模式 2 反向：`gm=0.0384615, ro=100000` → `Ic=0.001`、`VA=100`（往返误差 <1e-9）。
3. 手改保护：先写入、再手改 `gm`、再点写入 → `gm` 保持手改值。
4. 不自洽提示：把 `gm` 手改成 `0.05` 而 `Ic` 仍是 1mA → 出现「相差 30%」提示。
5. `Vt` 改成 0.025 → 重算后 `rπ` 随动（不被缓存住）。

变异两条：
- 把 `gm = Ic/Vt` 写成 `gm = Ic*Vt` → 第 1 条红；
- 去掉「手改保护」→ 第 3 条红。

## 不做

- 不做 SPICE 那种器件级模型库（只有 π 模型与推导）。
- 不做温度扫描（`Vt` 只有一个值，可手改）。
- 不做"点任意空白处生成节点"（那是自由画布，仍不做）。
