# 计划书 · R2：把主角换成装配台

> 老大定调：**项目的亮点是装配台，不是 28 张固定例子。**
> 所以 R2 不是「再补几个入口」，而是**把主线从「选模板 → 看讲解」改成「贴题 → 读结构 → 进装配台」**。固定例子降级成样例库。
> 顺序：T1（拖动误触搜索，半小时）→ T2/T3（AI 只读图 → 结构 → 装配台）→ T4（贴题页双出口）→ T5（叙事重排）→ T6（原 R2 的收尾项）。

## 0. 一句话

同一个数，两种入口：**讲解页**看推导，**装配台**看结构。AI 只负责把题面读成结构草稿，**不产生任何数值结论**。

## 1. 现状与差距

| 现状 | 差距 |
|---|---|
| `#/solve` 解析出「模板 + 参数」→ 跳 `#/t/<id>?p=` | 只能落到固定模板，改不了结构；而装配台才是能改结构的地方 |
| `#/lab/t/<id>` 支持 `?g=`（分享图）与 `?p=`（参数覆盖） | 没有「从题面生成图」这条路 |
| AI 已能读文字/图片出 `ProblemCardDraft` | 输出的是「模板 + 参数」，不是「结构」；也没有出口到 lab |
| 拖动器件会触发浏览器搜索 | 原生 drag 没被拦住（`user-select` / `draggable` 没关） |

## 2. T1 · 拖动不许触发浏览器搜索（P0，0.3 天）

症状：拖画布上的器件，松手后浏览器拿选中的文字去搜索（用户机器上留了 `固定铰 P = 150 kN L = 2 m` 的 bing 搜索记录）。

修法（三处一起，缺一不可）：

1. 画布容器 `select-none` + `-webkit-user-drag: none`；`svg text { user-select: none }`（已加，不够）
2. 每个可拖 `<g>` 加 `draggable={false}`，并在 `onDragStart` 上 `preventDefault()`
3. `pointerdown` 里对画布区域 `e.preventDefault()`（**只对画布**，别拦输入框），`touch-action: none`

门禁 `check:drag`（走 CDP，`scripts/test-flows.mjs` 里加一条）：
在页面挂 `window.__dragStarts = 0; document.addEventListener('dragstart', () => window.__dragStarts++)`，然后 pointerdown → move 40px → pointerup，断言 `__dragStarts === 0`，且器件坐标确实变了。

## 3. T2 · AI 只读图：产出「结构草稿」（P0，1 天）

### 铁律（写进 system prompt 与门禁）

- **只读，不算**：不许出现任何反力/内力/倍率/结果；图上印的答案一律忽略
- **不许猜**：缺的几何、缺的支座类型、缺的载荷方向 → 留空并标「待确认」，不许填默认值充数
- **不许造拓扑**：结构只能落在「骨架族 + 白名单器件」里；超出就拒绝并说明原因

### 输出 schema（新增 `src/core/ai/labDraft.ts`）

```ts
type LabDraft = {
  templateId: string;                       // 骨架族，必须 ∈ 可装配 16 型
  skeleton?: string;                        // 组态：CE/CB/CC、cantilever、CS/CG/CD…
  fields: Record<string, {
    value: number | string;
    unit?: string;
    from: '题面' | '图' | '默认' | '用户';    // 来源必须逐项标
  }>;
  devices?: { id: string; kind: string; value?: number; label?: string }[];  // 只允许增删白名单内器件
  edges?: { from: string; to: string }[];   // 只允许骨架已声明端口之间的连接
  notes: string[];                          // 复述题面里它读到了什么、哪些没读清
};
```

`fields` 里**没有值为「默认」的项必须显式写 `from:'默认'`**，装配台据此标琥珀。

### 接入点

`#/solve` 的解析结果区新增一块「结构草稿（AI 读图/读文，仅结构）」：

- 逐项显示 `名称 / 值 / 来源`，来源为「默认」的整行琥珀
- 底部一句固定文案：**「这一块只描述结构，不出任何数值结论；数值由装配台的求解器算。」**
- 有 `templateId` 不在可装配列表 → 直接给「这一型没有可装配骨架」+ 去讲解页的按钮

## 4. T3 · 结构导出到装配台（P0，0.5 天）

### 实现

新增 `src/core/lab/draftToGraph.ts`：

```ts
export function draftToGraph(draft: LabDraft): { ok: true; graph: CanvasGraph } | { ok: false; reason: string };
```

内部复用现成件：`freshSkeleton(templateId, spec, defaults)` 先建骨架 → `applyParams` 落参数 → `devices/edges` 只做**白名单内的增删**。不新写求解路径。

跳转：`#/lab/t/<templateId>?g=<encodeGraph(graph)>&from=题面`，并在页头挂徽标「来自题面 · 结构与参数可改」。

### 门禁 `check:labimport`（最强的一条）

1. **同解**：对可装配 16 型各取一个 draft，分别走
   - 模板路由 `#/t/<id>?p=…`
   - 装配台路由 `#/lab/t/<id>?g=…`

   两条路的 `result` 必须**逐位相等（≤1e-12）**，`validatedAt` 不参与比较。
2. **白名单**：draft 里塞一个非白名单器件（如 `A3` 加 `V2`）→ `draftToGraph` 拒绝并给人话
3. **不猜**：`fields` 里 `from:'默认'` 的键，装配台必须显示琥珀「未在题面出现」
4. **变异**：把 `draftToGraph` 里丢一个参数（比如不写 `P`）→ 第 1 条红

## 5. T4 · 贴题页改造（P0，0.5 天）

`#/solve` 的结尾不再只有一个「开始拆解 →」：

- 主按钮：**「进装配台看结构 →」**（青色，落 `#/lab/t/<id>?g=…`）
- 次按钮：**「看讲解 →」**（描边，落 `#/t/<id>?p=…`）
- 一行小字：「两边是同一个求解器；装配台能改结构，讲解页能看推导。」

同时把页面文案从「选题型 28 型」改成「贴题 / 选题型 / 从样例库挑一个」，样例库入口放次位。

## 6. T5 · 叙事重排（P1，0.3 天）

- **首页 hero**：标题与一段话改成装配台口径（「把一道题拼成一张图，让求解器替你算」），主按钮 `进装配台`；`贴一道题` 次之
- **卡片区更名**：「点开就能算的 28 型」→「样例库 · 28 型」，说明加一句「样例只是起点，改结构去装配台」
- **关于页**：先讲装配台（怎么拼、怎么改、三种求解器），再讲样例库；覆盖表保留
- 不改配色与令牌（这轮不动 UI 视觉）

## 7. T6 · 原 R2 的收尾项（P1，1 天）

1. `#/lab` 首页三栏：机械 / 电路 / 数字，每栏写「可装配 N 型 · 不适用 M 型（原因）」，`#/lab/digital` 从首页可达
2. 参数实验场接进装配台：可装配 16 型挂 `ParamSpec` 滑杆，改完即时重算（复用 80ms debounce），结果区标「本次参数」
3. `params` 与 `appliedRules` 常驻可见；「来自默认值」标琥珀
4. 12 型「不适用」卡：每型一句专属原因（不许复制同一句），点「去例题页」真的到 `/t/<id>`
5. **D1–D3 二选一**：接 live 重算，或在页面明写「这三型是快照管线，改参数不重算」——不许含糊
6. 撤销按钮 tooltip 写清「撤销会连 `appliedRules` 一起回退」

## 8. 门禁（本轮新增 4 道）

| 门禁 | 断言要点 |
|---|---|
| `check:drag` | 拖动全程 `dragstart` 计数为 0；器件坐标确实变化 |
| `check:labimport` | 同解 ≤1e-12（16 型）/ 白名单拒绝 / 默认值琥珀 / 变异 |
