### R3-2.0 · 修订（2026-11-11 定调：AI 只做识图且默认关、首页只做「贴题 → 看结构」、整体 UI 照 Codex 主页重做）

**先给探针结果（我实打过的，不是查文档）**：

| 探针 | 结果 |
|---|---|
| `GET https://api.deepseek.com/models` + 用户 key | `HTTP 200`，两型：`deepseek-flash`（V4.1-Flash，`input_modalities: ["text","image"]`）、`deepseek-v4-pro`（**text only**） |
| `POST /chat/completions` + `image_url` dataURL + `model=deepseek-flash` | `HTTP 200`，`prompt_tokens 226`，能读到图内容 |
| 同上，system 要求「只输出 JSON、不要围栏」，`max_tokens 900`、`temperature 0` | `HTTP 200`，`content` 恰好 `{"color":"pink"}`，`finish_reason: stop`，`completion_tokens 87` 其中 **80 是 reasoning** |

→ **结论：一把 key 就能同时跑聊天和识图，模型选 `deepseek-flash`。** 三条硬事实写进实现：①`content` 与 `reasoning_content` 是两个字段，**只读 `content`**；②`max_tokens` 必须 ≥600（thinking 会吃掉预算，设 40 会只吐 reasoning、`finish_reason=length`、`content` 空）；③不用 `response_format`，靠 prompt + 已有 `extractJson` 兜围栏。

**改什么：**

- **AI-1 入口从「搜题」变「识图」**。文字题面继续走现有规则解析（离线、免费、12 类），AI 不再用来猜题型；AI 唯一的活是**把图读成结构**（`LabDraft`，R2-T2 已交付的契约与铁律不变：只读不算／不许猜／不许造拓扑）。
- **AI-2 不随便用：CV 优先，AI 兜底且默认关**。主路径是 R3-2.5 的纯 CV。识图能力保留在代码里，但**默认关闭**，只在 `#/lab` 的「高级」里有一个「本场开启 AI 识图」开关（本次会话有效，刷新即关）。开启后，满足下列任一条件才出现「让 AI 再看一眼（1 次）」按钮，**用户不点就不调 API**：①CV 的长导线 recall 估计 <95%（线段数明显少于结点数）②出现白名单外的未知符号 ③读到数值但单位缺失 ④CV 与规则解析结论冲突。点过即置灰并写明「本次已用过」。默认关闭的理由：评委打开页面时**零请求、零额度、零 key 暴露**，演示要用手写题时我们自己打开。
- **AI-3 不用用户自己的 key**。删掉 `#/solve` 的设置抽屉（baseURL/key/model/vision 四字段）、`presets.ts` 的 `custom` 入口、`sd.ai.v1` 的 localStorage 存储，以及 README/关于页一切「BYOK/自带 key」的说法。改为固定配置，集中在一个新文件 `src/core/ai/config.ts`：
  ```ts
  export const AI_CONFIG = {
    baseURL: 'https://api.deepseek.com',
    model: 'deepseek-flash',
    apiKey: 'sk-***',          // 比赛期固定；赛后轮换
    maxTokens: 900,            // 必须 ≥600：thinking 计入预算
    timeoutMs: 30000,
  } as const;
  ```
- **AI-4 首页不做聊天，只做一件动词**（2026-11-11 决策，取代先前的「首页放聊天」）。首页 hero 下方就是一个输入框，只有一个动作：贴题面文字或贴图 →「看结构 →」→ `LabDraft` → 装配台。**不接对话**：聊天会把这个产品稀释成又一个套壳，而且「AI 代算」的口子一开就守不住。选题引导仍由 `#/wizard`（六问）和 `#/scope`（能解/要简化/不覆盖）承担。
- **AI-4b 不接百度文心**（同一决策）。理由三条：①它同样要在前端内嵌一把 key，**没有解决暴露问题**，只是把风险换了个地方；②它是纯文本，接了等于**砍掉识图**换来一份聊天，能力上是净减；③多一个 provider 就多一套错误映射、一套限流、一份门禁与文档，成本 0.5–1 天，收益为零。DeepSeek 这条已经端到端验通（见上表），就用它。
- **AI-5 UI 整体照 Codex 主页重做**。一列居中、大字标题、一个主操作、下面一张真产品图、极简 chrome、冷调深色：
  - 首页 = 顶栏（`拆解台 SolveDeck` + 仓库/关于两个文字链接）→ hero（`把一道工科题，拆成看得见的五步` + 一句说明 + 输入框 + 主按钮`先看结构` + 次按钮`随便看看例子`）→ 产品图（装配台真截图，细边框、无阴影）→ 三条能力（`能解什么`/`怎么算的`/`凭什么可信`）→ 页脚。
  - 删掉现在的 hero 右侧预览卡、三个数字、卡片网格首屏——**样例库下沉为第二屏**（`样例库 · 28 型`），首屏只留产品本身。
  - `#/solve`、`#/wizard`、`#/about`、`#/lab` 统一同一个外壳：`max-w-[1120px]` 单列、`px-6`、标题层级 30/20/14、卡片发丝线不发光、accent 每屏最多一处。
- **AI-6 门禁**（改写 `check:ai`、新增 `check:vision`）：
  - `check:ai`：源码里 `https?://` **只允许**出现在 `src/core/ai/config.ts`；该文件零 import 请求模块；页面默认态（未点按钮）**零 fetch**；设置抽屉的 DOM 不复存在；key 只在该文件出现一次（`grep -c 'sk-'` = 1）。
  - `check:vision`：mock fetch 断言 `model === 'deepseek-flash'`、`max_tokens >= 600`、body 里 `image_url` 是 `data:image/` 开头、解析只取 `choices[0].message.content`（构造一个带 `reasoning_content` 的假响应，断言不会把 reasoning 当答案）、AI 失败时 CV 结果**照常保留**且页面只多一行提示。
  - `check:drag`/`check:labimport` 保持。

**风险，写在这里免得以后忘**：前端内嵌 key 等于公开——任何人打开页面都能从 bundle 里取出来。可接受的前提是：**默认关闭**（不打开开关就一次都不发）、单一入口、只用 `deepseek-flash`、客户端限流（每会话最多 3 次识图）、**比完赛立刻在 DeepSeek 控制台轮换这把 key**。要真正保密只有一条路：加一层自己的转发（静态托管做不到），那属于 R4 之后的事。

### R3-2.5 · 纯 CV 识别（H-15，2026-11-11 决策：默认路径从 AI 换成 CV）

**决策**：读图默认走本地 CV，不再默认调模型。AI 那条（R2-T2/T3 已交付）**保留为可选入口**，不删代码——删掉是净损失；但按钮次序与文案改成 CV 优先，无 key 时也一样能用。

**先给一个真实测量，别拍脑袋**（今天用 `docs/shots/A3-CB.png` 跑的第一版原型，只用 PIL+numpy，按行/列扫长游程 + 局部密度找结点）：

| 指标 | 真值 | 第一版原型 | 结论 |
|---|---|---|---|
| 长水平导线 | 5 | **3** | 漏检（被器件本体打断的段没合并） |
| 长竖直导线 | 4 | **1** | 严重漏检（`MINLEN` 过高 + 断成小段） |
| 结节点（dot） | 3 | **18（误报 15）** | 局部密度法把符号内部笔画、晶体管圆都当成了结点 |

→ **结论：不是几行扫描就能成的活。** 差的不是「能不能看出来」，是「怎么把描边图元化成线段、怎么把结点和粗笔画分开」。

**分四步，每步有数才进下一步：**

- **CV-1 测量原型（0.5 天）**：搭评估集（47 张 `docs/shots/*.png` + 35 份快照真值），脚本输出 recall/precision 表。**这一步只量不做产品**。
- **CV-2 线段图元化 + 符号匹配（1.5 天）**：二值化 → 连通域/形态学抽骨线 → 按方向聚成线段（**跨过器件要能合并**）→ 用 `public/symbols/electronics/*.svg` 栅格化成多尺度模板做符号匹配（电阻方框 / 菱形受控源 / 晶体管圆 / 电源圆）→ 结点判定改成「实心圆面积 + ≥3 条线段交汇」双条件。
- **CV-3 值 OCR（0.5 天）**：Tesseract 数字/希腊字母，`Rc 2.0k`、`β=100`、`gm=1mS`；认不出的标「待确认」，绝不猜。
- **CV-4 接进现有管线（0.5 天）**：CV 只产出 `LabDraft`（复用 R2 已有的 `draftToGraph`），落到 `#/lab/t/<id>?g=…`，并复用 `check:labimport` 的「同解 ≤1e-12」。

**阈值（达不到就退回辅助模式，不许硬说能用）：**

| 指标 | 门槛 |
|---|---|
| 长导线（≥120px）recall | ≥ 95% |
| 长导线 precision | ≥ 90% |
| 结节点 recall | ≥ 90% |
| 16 型「图 → 结构 → 解」与快照同解 | ≤ 1e-12 |

达不到 → CV 只做「辅助提示」（把识别到的候选结构画成半透明草稿，让人点确认），页面文案写清「截图能认、手写请手填或走 AI」。

**明确不支持（写进页面，不要藏）**：手机拍手写作业、与 `public/symbols` 不同体系的教科书符号、旋转超过 ±15° 的扫描件。这三类只能走 AI 或手填。
