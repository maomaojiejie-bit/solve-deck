## 3. F9 修复验证（上一轮 high 级问题）

上一轮（5180）：装配台加元件后通用 MNA 把耦合电容按直流开路算，输入到不了基极 → **Av=0、VBE=VCE=IC=0**（旧报告 §F9，line 97–109）。

1. **代码**：`src/core/lab/netSolve.ts` W22-B 引入 `mode: 'dc' | 'ac'`——dc：C 开路/L 短路（偏置测量）；ac：C 短路（经 `acAliases` 并网）/L 开路。`NET_AC_CONFIG.honorMode`（:88）为变异位；mode 取值 :407；电容并网 :434-435；AC 口径 note :768（仅当 `mode==='ac' && acAliases.size>0` 才发）。gain/Ri/Ro 测量在通用路径恒走 ac（resolve.ts）。
2. **门禁**：`check:netsolve` 33 项含「dc-ac 口径」+ honorMode 变异；`check:labresolve` 21 项含「删Rs 与 Rs 短接通用等价」。均 PASS（§1）。
3. **实测**（5181，A3 骨架删 Rs 后走通用路径）：

```text
电压增益（1V 测试源）
Av = V(n-vo) / V(n-q:b) = -63.052
输入 n-q:b  1 V    输出 n-vo  -63.0517 V
图上这台电压源没标数值，按 1V 测试源求值（输出即增益，输出网取自tag 命名网）；Ri/Ro 要看端口，这一版不给。
```
