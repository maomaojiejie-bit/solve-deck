# 部署清单 · SolveDeck

> 目标：`dist/` 直接挂到 `https://xxx/solve-deck/` 这类子路径下也能正常打开。
> 路由是 hash（`#/t/A3`），不需要服务器 rewrite；关键是资源路径必须是相对的。

## 一、构建

```bash
npm run verify          # 八道门禁 + tsc + vite build
```

- `vite.config.ts` 已设 `base: './'`，`dist/index.html` 里的 JS/CSS 应为 `./assets/...`，不是 `/assets/...`。
- `shotsPlugin` 会把 `docs/shots/` 拷到 `dist/shots/`，about 页用 `BASE_URL + shots/...` 引用。

## 二、Qoder Sites 部署

1. 在 Qoder Sites 新建站点，选择静态站点 / 上传 `dist`。
2. 如果站点平台要求一个子目录，把 `dist` 的内容放到 `solve-deck/` 下，入口为 `solve-deck/index.html`。
3. 不需要配置 SPA fallback：所有页面都在 `#/` 后，直接访问 `https://xxx/solve-deck/#/t/A3`。
4. 发布后用下面的自检逐项过一遍。

## 四、本机自动自检

```bash
npm run build
node scripts/serve-subpath.mjs
```

脚本会把 `dist` 挂在 `http://127.0.0.1:5199/solve-deck/`，headless 打开结果页与 about 页，
断言页面真的渲染出内容，并产出：

- `docs/shots/deploy-A3.png`
- `docs/shots/deploy-about.png`

如果部署后白屏，先看这两条：`dist/index.html` 是否还是 `/assets/...` 绝对路径；
`dist/shots/` 是否存在。前者是 `base` 没生效，后者是 `shotsPlugin` 没跑。
