## 1. 交付四件

### 1.1 `src/core/mechanics/spec.ts`
`MechSpec` 类型，**字段名与库一字不差**（就是 `kind/length/supports/loads/section/stations/units`）。
不许改名、不许嵌套改造、不许加 `id` 之外的自定义字段。

### 1.2 `scripts/export-fixtures.mjs`
对下面 8 个 spec 各跑一次库脚本，把 `{ spec, expected }` 写成 `fixtures/mech/<name>.json`：

```
M1-axial-01      bar    A=2.0e-4 m², P=40 kN(axial)        两端 pin
M2-torsion-01    shaft  d=40 mm, T=1.0 kN·m               一端 fixed
M3-cantilever-01 beam   L=2, P=10 kN@x=1                  fixed@0
M3-simple-P-01   beam   L=4, P=20 kN@x=2                  pin@0 roller@4
M3-simple-q-01   beam   L=4, q=5 kN/m 全跨 q0=q1=5        pin@0 roller@4
M4-rect-01       beam   b=0.1 h=0.2, 同 M3-simple-P-01 截面
M4-circle-01     beam   d=100 mm, 同 M3-simple-P-01
M8-combined-01   beam   L=2, axial P=50 kN + point_moment 50 kN·m
```

其余 9 型（M5/M6/M7/S1–S7）这波**不要**造 fixture —— 它们不在库里，等各自实现时再补。

### 1.3 `src/core/mechanics/solve.ts`
按库的算法复刻 M1–M4 与 M8 的应力：

```
N(x) = -Σ_{a<x} Fx     Q(x) = +Σ_{a<x} Fy
M(x) = +Σ_{a<x} [(x-a)·Fy - Mz]     T(x) = -Σ_{a<x} Mx
σ(y) = N/A + M·y/Iy      τ_torsion = T·ρ/Ip
```

反力：`ΣFx=0、ΣFy=0、ΣM(左端)=0`，`shaft` 再加 `ΣMx=0`；未知量数 > 方程数 → 返回
`{ determinate: false, message: '静不定，当前只解静定' }`，**不要凑答案**。

### 1.4 `scripts/check-mech-parity.mjs` → 接进 `npm run build`
对每个 fixture：TS 结果 vs `expected`，相对误差 **1e-9**；不一致打印
`型 / 字段 / TS 值 / 库值 / 相对误差` 并 `exit 1`。
