# 短令 W19：装配 M5 / M7 只出通用内力图 —— 让「问的量」从图里来

## 1. 现象（可复现）

装配台里打开 M5（弯曲变形）、M7（压杆稳定），**不改任何东西**，求解后底部是「这一型题库里没有讲解稿，下面是通用求解结果」，面板里只有 N/Q/M 三联图与反力 —— 没有 `δmax`、没有 `Pcr`。改一改也一样。

## 2. 根因（读码，不是猜）

- `src/core/lab/resolve.ts:94`：**只有** `blocking.length === 0 && healedSeries === undefined` 才走 `template`；否则落到 `:105`/`:145` 的 `generic`（`frameSolve` → 反力 + 内力曲线）。
- M5/M7 的 `reduce` 必然出 blocking：它们的讲解稿要求截面与 `E`（M5 要 `EI`）、柱长与约束（M7 要 `L`、`μ`），而骨架里这些是**可选**的，用户不改就是缺 → 永远到不了 `template` 分支。
- `generic` 只呈现**引擎原始量**：`GenericResult` 的 `FramePanels` 画 N/Q/M。**「这张图问什么」这一层不存在**，所以 M5 拿不到位移、M7 拿不到稳定。

> 一句话：不是解错了，是**从来没问过这张图要什么**。

## 3. 改法（四步）

### P1 新增 `interpretQuestion(graph, family) → Measure[]`（半天）

纯函数，只看图，不看 `templateId`：

| 判据（梁族） | Measure |
|---|---|
| 有支座 + 有载荷 | `react`（反力） |
| 有 ≥1 根梁段 | `internal`（N/Q/M 与极值） |
| 给了截面 `b/h` 或 `I` 且给了 `E` | `stress`、`deflection` |
| 构件全部为**轴向受压**且两端铰/固定 | `stability`（`λ`、`Pcr`）；判据不满足则**不产出**，而不是给内力图充数 |

### P2 两个新视图（一天）

- **位移视图**：`frameSolve` 的节点位移场 → `ChartSpec` 折线 + `δmax` 与位置；顶部一行「本图未给截面 → 只给位移形状，不给数值」或给数值，二者互斥且写清。
- **稳定视图**：`λ`、`λp`、`Pcr`、`σcr`；**做不了就明说**「本图未给柱长与约束，无法判稳定」，不出内力图。

### P3 `reduce` 的「缺参数」重分类（半天）

已经存在的机制（别重造）：`reduce.ts:203` 把「参数在图上找不到来源」推进 `blocking`，`:222` 再把 `blocking` 与非阻断的 `open.warnings` 合并成 `problems`，`resolve.ts:90` 用 `isBlockingProblem` 过滤。**问题在于「讲解稿要用、但解不需要」的参数也被塞进了 blocking**（M5 的 `b/h/E`、M7 的 `L/μ`），于是一缺就早退。

改法：给 `pick` 加一个来源标记 `neededBy: 'solve' | 'narr'`（默认 `'solve'`）。`reduce` 里缺 `narr` 类参数时推 `warnings` 而不是 `blocking`；`resolveLabSolve` 因此只有真「解不成立」才早退。

### P4 文案与门禁（半天）

- 横幅分三态：**有讲解稿** / **无讲解稿但有解**（「按图求解，不播五步」）/ **只给原始量**（真认不出时才出现）。
- `scripts/check-measures.mjs`（六条）：
  1. 同一张图换入口（`M5` / `M7` / `M3`）→ `measures` 逐位相同；
  2. M5 骨架 → 必含 `deflection`；
  3. M7 骨架缺柱长 → 必**不含** `internal`，且含 `stability` 或明确拒绝；
  4. 电路族 A3 骨架 → 必含 `gain`，且与 A5 的 `measures` **不同**（这条直接在门禁上锁住用户看到的问题）；
  5. 混合族图 → 拒绝；
  6. 变异：把 `interpretQuestion` 的判据改回「读 templateId」→ ① 必红。

## 4. 红线

- 不动 `src/core/templates/**` 公式与 35 份快照；不调容差；不引第三方求解器。
- 现有 `check:labresolve`（21 项）里「删 Rs → N 档」等断言必须继续绿。

## 5. 验收（人手点五下）

1. 装配 M5 → 出现 `δmax` 与挠曲线（不是只有内力图）；
2. 装配 M7 → 出现 `Pcr`；缺柱长时明说「无法判稳定」；
3. 装配 M1 → 轴力图（已有，不得退化）；
4. 装配 A3 与 A5 → 两张图的 `measures` 不同（增益 vs 分压/工作点）；
5. 空白搭两级共射 → 仍出 `gain`（模板里没有也要给）。
