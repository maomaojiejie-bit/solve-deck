## W22-B · P0：交流口径（报告 F9 + F10，1.5 天）

这是「装配台加元件提高难度」这条核心承诺的唯一硬伤，**必须先解决口径，再谈结果对不对**。

1. **`netSolve` 加 `mode: 'dc' | 'ac'`**：
   - `dc`：现状（C 开路、L 短路）—— 用于工作点 / 偏置类 measure。
   - `ac`（小信号增量）：**C 按短路**（stamp 成 0 Ω → 两端网合并）、**L 按开路**。装配台的 `gain` / `Ri` / `Ro` 类 measure 一律走 `ac`，并在结果卡标注「交流小信号口径：C 短路、L 开路」。
2. **输出网选择**：优先「命名网」（`tag` / `Vo` / `vout`），其次 `|v|` 最大非地网；**删掉「取晶体管 c 脚网」作为唯一依据**（`src/core/lab/measures.ts:614` 那段的兜底顺序改过来）。
3. **几何并网收紧**：`buildNets` 优先用显式端点（`edge.from/to` 是 `node:pin` 字符串时就按引脚归属），`touchesPolyline` 只作 fallback；并对「导线穿过器件 body」直接拒答并指路（判据复用 `check:schematic` 的 S6）。
4. **F10 白名单统一**：A3 的归约白名单**接受 C**，语义为「交流短路 / 直流开路」，`+C` 的按钮文案与器件行都标这句；不再出现「加了就被判白名单外」。
5. **门禁**：`check:netsolve` 加三条 —— 同一张图 `dc` 与 `ac` 的增益必须不同（否则口径没生效，变异哨兵：把 `ac` 退回 dc 即红）；命名网优先于 `|v|max`（变异：改成取 c 脚即红）；穿 body 的图必须拒答。
6. **`#/about` 的「现算」措辞**补一句口径：「现算按交流小信号，C 视为短路」——承诺与实现对齐。

## A 批补充：同一个 bug 的其它出现处（老大 m05630 亲自撞到）

用户现象：「电路里加多个电阻，R 会被复用加不进去，而且数值没法改」。

### 根因只有一个：id 由 label / length / index 生成

`src/core/lab/ops.ts:485` 的守卫比的是 `node.id === op.label`（'R' 对 `n-add-R`，永不相等 = 死守卫），`:491` 接着造 `id: n-add-${op.label}`。于是第二个 R 与第一个 **id 完全相同**：

- React 以 id 作 key → 第二行根本不渲染（用户看到的「加不进去」）
- 同 id 的行只有一行 → 在里面输入数值，`nodes.find(n => n.id === op.nodeId)` 命中的是第一个（用户看到的「数值改不了」）

**两条症状是同一个根因**，不需要分别修。

### 同类点位全表（都是「id 会撞」，都归 A 批）

| 位置 | 生成式 | 撞法 |
|---|---|---|
| `ops.ts:491` | `n-add-${op.label}` | 连加两个同类器件（用户撞到的） |
| `ops.ts:501` | `e-add-${op.label}` | 同上那条连线 |
| `ops.ts:481` | `n-cmp-${count+1}` | 加两个复合模块、或删一个再加 |
| `ops.ts:536` | `e-pin-${edges.length}` | 删一条线后再连一条（F3） |
| `ops.ts:998` `ops.ts:1050` | `n-cmp-${blockIndex}` | 展开/折叠后 index 重排 |
| `ops.ts:989` | `in-${edge.id}` | 同一段展开两次 |
| `ops.ts:643/644` | `${edgeId}-1/-2` | 切段后再切同一段（低危，顺手统一） |

`graphToModel.ts:166` `c-${index}` 每次重建不落盘、`netSolve.ts` 的 `x:${id}` 是求解期临时 id，**这两处不用改**。

### 修法（一条，覆盖全部）

1. `GraphMeta` 加单调计数 `seq: number`（只增不减，随图保存/分享）。
2. 新增唯一入口 `nextId(graph, kind)`（`lab/ids.ts`），所有 add* 操作改走它：`n-add-3`、`e-pin-7`、`n-cmp-2`。
3. 死守卫改成「用**将要生成的新 id** 比」，并保留同名提示（`已有同名器件「R」`）→ 改名 `R2` 或直接用新 id。
4. 兼容：读旧图时把 `seq` 初始化为「现有 id 里数字后缀的最大值 + 1」。
5. 门禁 `scripts/check-ids.mjs`（A 批）：真点击跑四条 —— 连加两次同类器件 id 不同 / 加两个复合模块 id 不同 / 删一条线后再连一条 id 不复用 / 展开同一复合两次 id 不同；再配一条变异（把 `nextId` 改回 `n-add-${label}` 必须红）。

`Lab.tsx:2583` `ValueInput` 输入框固定 `w-[64px]`，`0.000001` 这类值在框里显示不全（值本身是对的，旁边读数也全）→ 改成 `min-w-[64px] w-full max-w-[104px]` 或按字符数自适应。
