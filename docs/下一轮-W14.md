## 任务 C · 撤销 / 重做（本轮主角）

现在 `Esc` 只能撤销"拖动"这一种动作，删了器件、封了复合器件都回不去 —— 这是拼接台最缺的一块手感。

### 设计（照这个做，别扩大）

- 状态：`{ graph, appliedRules, params }` 快照栈，**上限 30 步**，超出丢最旧；
- 每次"改变结构"的操作入栈：`deleteDevice / addDevice / addEdge / addMember / deleteMember / wrapComposite / expandComposite / collapseComposite / unwrapComposite / changeKind / setSemantic`；
- **不入栈**：拖动位置（拖完只在最后写一次，且与上一步合并）、参数实验的滑杆、折叠展开 UI；
- 快捷键：`Ctrl+Z` 撤销、`Ctrl+Shift+Z`（或 `Ctrl+Y`）重做；顶栏加两个图标按钮，都带 `title`；
- 换题型 / 恢复骨架 / 从分享链接载入 → **清空栈**（不许跨题型撤销）；
- 撤销后 `appliedRules` 一起回退（否则"已删除器件"的记录会留在预览里撒谎）。

### 任务 D · 顺手统一删除手势

- 选中器件后按 `Delete` / `Backspace` = 删它（现在只能点行里的 🗑）；
- 双击器件 = 焦点到该行（不是删除，避免误触）；
- 删除前对**有下游影响**的（删了以后 `reduce` 会归约失败）给一次确认，其余直接删 + toast「已删除，可 Ctrl+Z 撤销」。

### 门禁 `check:undo`（新，接进 `build`）

1. 删器件 → `Ctrl+Z` → 图与 `appliedRules` 都回到删前（逐字段比较）；
2. 撤销后 `Ctrl+Shift+Z` → 回到删后；
3. 栈深 30：连做 35 次操作，只能撤 30 次，第 31 次无变化且按钮置灰；
4. 换题型后栈清空（`Ctrl+Z` 不动新图）；
5. 拖动不产生独立历史（拖 5 次再撤一次 → 位置回到拖动前，不是撤 5 次）；
6. `Delete` 键删选中器件与点 🗑 等价（同一图结果）。

**变异两条**：① 撤销不回退 `appliedRules` → 第 1 条红；② 把栈改成无上限 → 第 3 条红。
