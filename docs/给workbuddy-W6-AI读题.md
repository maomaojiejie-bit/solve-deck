# 给 WorkBuddy · W6：站内 AI 读题（把「例题」变成「能解你的题」）

目标只有一个：学生在 `#/solve` 里贴一段题目文字（或一张题图），系统**选出模板 + 抽出参数 + 显示题面待确认**，点确认后跳到既有的 `#/t/<id>?参数...` 页面，走同一套 solver 与门禁。

## 0. 三条不变式（违反即 fail）

1. **AI 不产生任何数值结论。** 屏幕上每个数字只能来自两处：用户确认过的题面 / solver。AI 的输出里**不许出现**答案、中间结果、Av/Pcr/σmax 之类的值。
2. **不静默降级。** 没配 key 就说「未配置 AI，已用规则解析」，规则解析也要能跑通最常见的一类题（"悬臂梁 L=2m，端部集中力 10kN"），不能白屏、不能假装成了。
3. **抽出来的东西必须是「待确认」状态。** 参数卡用琥珀色标成待确认，用户点过「确认无误」才允许跳转。不许默认放行。

## 1. 页面 `#/solve`

三块，从上到下：

- **输入区**：`<textarea>`（≥6 行，可粘贴中文题目）+「粘贴图片」按钮（`paste` 事件收 `image/*`）+「AI 解析」按钮。
- **解析结果卡**（解析后出现）：
  - 一行「题型：`A3` BJT 三种组态 · 共射/共基/共集」+ 匹配理由一句话（AI 给的 `reason`，没有就写规则命中的关键词）。
  - 参数表：每行 `名称 | 值 | 单位 | 来源`（来源 ∈ `题面 / 默认值 / 待确认`）。**超出 registry 范围的**值标红并给出合法区间，不允许自动夹到边界。
  - 题面原文（可编辑，`textarea`），供对照。
  - 两个按钮：「确认无误 → 开始拆解」「改参数」。
- **空态**：直接给三个可点的例子（"悬臂梁 L=2m 端部 10kN"、"共射放大器 β=100 Ic=1mA Rc=2k"、"σx=100 σy=-20 τ=40 求主应力"），点了就把文字填进输入框并自动解析（规则解析即可）。

跳转用现有 URL 约定：`#/t/A3?Rc=2000&beta=100`（只带非默认值，复用 D1 的 `query.ts`）。

## 2. 数据契约

```ts
type AIDraft = {
  templateId: string;        // 必须在 registry 里，且 status==='ready'
  params: Record<string, number | string>; // key ⊆ 该模板 ParamSpec.key
  reason: string;            // ≤40 字，中文
  given: string;             // 题面原文（用户可改）
  source: 'ai' | 'rule';     // 谁解析的
  unsure: string[];          // 待确认的 key 列表
};
```

校验（全部不通过就退回重写一次，再失败给可读错误，不许硬猜）：

1. `templateId` 存在且 ready；
2. `params` 的 key 必须在该模板的 `ParamSpec[]` 里；
3. 数值必须落在 `[min,max]` 内，越界 → 标红 + 说明区间；
4. 单位：题面里出现的单位必须能被识别成 `m/mm/kN/N/MPa/GPa/Ω/kΩ/mA/A`，识别不了就要求人填；
5. **禁止裸结果**：AI 返回的字符串里若出现「答案/结果/Av=/σ=/Pcr=」这类字样，整个 draft 作废重写（AI 只准报参数与题型）；
6. `unsure` 里的 key 一律以「待确认」呈现，即使值合法。

## 3. 三种接入形态（按优先级实现）

- **A. 无 key（默认，必须可用）**：纯规则解析。中文关键词 → 模板（`悬臂|悬臂梁|固定端` → M3-cantilever；`简支|跨中` → M3；`共射|共集|共基` → A3 变体；`主应力|莫尔` → M6；`压杆|稳定|欧拉` → M7…至少覆盖 10 型），数字用 `/([A-Za-zα-ωΑ-Ω]{1,3})\s*[=＝]\s*(-?\d+(?:\.\d+)?)\s*(kN|N|mm|m|MPa|GPa|Ω|kΩ|mA|A)?/g` 抓。抓不到的参数留在 `unsure`。
- **B. BYOK**：设置抽屉里四个字段（`baseURL` / `apiKey` / `model` / 可选 `proxyURL`），存 `localStorage`（`sd.ai.v1`）。`fetch` 直调 `chat/completions`，`response_format: { type: 'json_object' }`，**不引任何 SDK**。
- **C. 自建代理**：同一份字段，地址指给代理，前端代码零改动。

图片：把图片转 `dataURL` 塞进 `messages[0].content` 的 `image_url`（形态 B 才支持）。**图片只在内存里用，不落盘、不写 localStorage**，并在设置抽屉里写明「图片会发往你配置的服务商」。

## 4. Prompt（照抄）

```
你是工科题目结构化器。只做三件事：判断属于哪个模板、抽出参数、给出匹配理由。
禁止计算任何结果（不许出现答案、内阻、增益、应力、临界力等数值结论）。
模板清单（id: 描述）：
<附 registry 里 status==='ready' 的 28 条 id + title>
参数约束：
<附所选模板的 ParamSpec：key/label/unit/min/max>
输出 JSON：{"templateId":"...","params":{...},"reason":"≤40字","unsure":["key"]}
只输出 JSON。
```

## 5. 门禁 `scripts/check-ai.mjs`（零网络）

1. **规则解析 10 例**：10 段中文题面 → 必须选中正确模板 + 至少抽对 1 个参数（值逐位相等）。
2. **mock provider**：注入一个返回固定 JSON 的假 provider，跑通「解析 → 校验 → 生成 URL」全链路，断言 URL 形如 `#/t/A3?Rc=2000`。
3. **拒绝裸结果**：mock 返回 `{"reason":"Av=-46.25"}` → 必须判为不合格并走一次重写，重写仍不合格则显示错误，**不许**把 `-46.25` 显示到页面上。
4. **越界不夹取**：mock 返回 `Rc=999999` → 标红 + 区间文案，跳转按钮禁用。
5. **无 key 文案**：未配置时页面必须出现「未配置 AI，已用规则解析」。

变异两条（写进报告）：① 把规则解析的模板映射删掉一条 → 例 1 必须 fail；② 把「禁止裸结果」的校验注释掉 → 例 3 必须 fail。

## 6. 不做

- 不做多轮对话、不做「问 AI 这题怎么解」（一旦放开，AI 就会开始产生数值结论，不变式 1 立刻破）。
- 不做题库爬取、不做用户上传入库。
- 不让 AI 直接改 URL 或改求解结果。

## 7. 报告

`verify` PASS 行 + `check:ai` 输出原文 + 三张图（`#/solve` 空态、规则解析结果卡、BYOK 解析结果卡）+ 十条规则解析例的命中表（题面 → 模板 → 抽到的参数）。
