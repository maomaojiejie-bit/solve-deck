## 3. 本轮新发现

### F1.【呈现】单位制切到 SI 后，结论大标题给出不可读的生值 Pa
- M1：`轴向拉压： σmax = 200000000 Pa`（同页表格写 `200 MPa`）
- M2：`扭转： τmax = 79580000 Pa`（表格 `79.5775 MPa`）
- M4：`弯曲应力： σmax = 30000000 Pa`（正文 `σmax = 30 MPa（[σ] = 160 MPa → 通过）`）
- 而 M3/M5 的标题是 `Mmax = 20000 N·m` / `δmax = 2 mm` —— 同样在 SI 下却是「量级归一」的写法。
- **危害**：9 位数要自己数零；且同一页两种写法。
- **建议**：标题也走统一 formatter（力→kN/N 自适应、应力→MPa、长度→mm）。

### F2.【呈现】反力表列固定为 `Fx / Fy / Mz`，扭转题缺 `Mx`
- M2 是扭转题（T=1 kN·m），反力表只写 `END-A · 固定端 Fx 0 · Fy 0 · Mz 0`，**扭矩反力 Mx 无处显示**，反而给了一个 `Mz = 0`。
- **危害**：学生会以为「固定端没有反力偶」，而实际是 `Mx = −1 kN·m`。
- **建议**：按题型增删列（扭转题显示 `Mx`），或统一显示六个分量并置灰无关项。

### F3.【内容】两张骨架的默认参数自己过不了自己的体检
- A4（NMOS）：`过驱动电压 1.919 V`，体检标注 `偏离 · 0.1–0.3 V 常见`；
- A2（BJT）：`静态工作点位置 30.9% Vcc`，体检标注 `偏离 · 33%–67% Vcc`。
- 默认骨架是用来「一打开就对」的示范，现在一打开就是「偏离」，用户第一屏就看到红字，容易误以为工具算错。
- **建议**：调默认参数（A4 降 VOV、A2 把 VCE 拉回 6 V 附近），或把这两条从「偏离」降级成中性提示。

### F4.【流程】A5/A7 求解后停在 N 档，下一步没有引导
- 芯片上写 `N · 数值已验证 · 等效图未核对`，正文只有一行小字：「还缺 bias 偏置 / coupling 耦合 / load 负载 —— 在归约预览点「按拓扑标全」（还缺 3 项）即可升 F 档看等效电路」。
- 但「分步求解」按钮已经点过、变灰了，用户会以为完事；那个「按拓扑标全」藏在右栏「归约预览」里。
- **建议**：求解完成时直接在横幅里给一个可点的「标全语义并升 F 档」按钮。

### F5.【文案】同一功能三种叫法
- 导出：M3 工具栏叫「导出图」，M3-cantilever 叫「导出装配图」，菜单项叫「存为 SVG · 矢量 / 存为 PNG · 2 倍图」。
- 复制链接：工具栏「分享此图」，结果区「复制链接」。
- **建议**：统一成「导出图」+「复制链接」，菜单项用「SVG（矢量）」「PNG（2×）」。

### F6.【布局】「换三种结构」把整个工作台推下一屏
- 点开后是一块通栏面板（三张卡 + 说明），高度约 320px，工作台整体被推下去；而用户多半只想快速换个拓扑看结果。
- 第三张「带外伸」是灰卡，占 1/3 宽，只有一句「缺带外伸梁的已校验快照，不硬造」——诚实，但空占地方。
- **建议**：改成工具栏下方的轻量分段控件（简支／悬臂／外伸（禁用）），或者浮层预览。

### F7.【内容】M3 与 M3-cantilever 的描述文字完全相同
- 两张卡都是「弯曲内力：V(x) / M(x)、载荷微分关系、简支/悬臂梁」；索引页只能靠 id 区分，工具栏里也一样。
- **建议**：M3-cantilever 改成「悬臂梁：固定端反力偶、自由端挠度」这类区分性描述。

### F8.【呈现】桁架题的内力表仍按梁的口径给 Q / M 列
- S5 每根杆都写 `N -7.07107/-7.07107 · Q 0/0 · M 0/0`；桁架构件只有轴力。
- **建议**：桁架只显示 N（或把 Q/M 列置灰隐藏）。

### F9.【稳定性·未定性】已求解的长结果页会让浏览器截图/合成持续超时
- 现象：求解后（页面约 5–6 屏），`bsk screenshot` 反复 `error: viewport screenshot timed out`；`reload` 之后立刻恢复。DOM 查询（VOM）始终正常，说明页面没死锁。
- 推测：常驻动画或超大 DOM 让合成器拿不到稳定帧。用户侧表现会是滚动卡顿、截图/导出变慢。
- **建议**：给 `.lab-panel` 之类的常驻动画加 `content-visibility: auto`，或让首屏外的图表懒渲染。

### F10.【存疑】导出菜单项的鼠标点击「点不动」
- 自动化的合成点击反复报 `the pointer target is covered or unavailable` / `drag endpoint is covered or no longer belongs to the requested element`；**键盘 Tab + Enter 能正常导出**（已实测生成 `SolveDeck-M3-cantilever-装配图.svg`）。
- 怀疑菜单在焦点变化时先被关掉（onBlur 卸载），导致随后的 click 落空。
- **建议**：改成 `onMouseDown` 触发，或只在点击外部/再次点按钮时关闭。

### F11（正面，建议保留）
- 均布放置器离开杆身会给引导：「均布只能落在杆上：把光标移到杆身」。
- 载入变体前有二次确认：「画布有未保存的改动 —— 载入「悬臂」会全部丢掉。仍要载入 / 取消」。
- 「带外伸 未覆盖」明确写「缺已校验快照，不硬造」。
- 导出 SVG 实测可用：15 KB、XML 合法、含 `固定端 / P = 10 kN / L = 2 m` 与支座图形（注意：导的是**当前画布**，不含结果标注与内力图）。
