## 3. R2 · 装配台最后一公里

这一批解决「用户找不到 / 改了不改结果 / 不信数字」三类问题。

1. **入口收拢**：`#/lab` 首页分三栏——机械 / 电路 / 数字，每栏写「可装配 N 型 · 不适用 M 型（原因）」；`#/lab/digital` 从首页可达（现在只能手打 URL）。
2. **参数实验场接进装配台**：`#/lab` 右侧目前只有「归约预览」，缺「改这个值会怎样」。给可装配的 16 型接上 `ParamSpec` 滑杆，改完即时重算（复用 `#/t/` 的 80ms debounce），并在结果区标「本次参数」。
3. **数字可信**：`reduce()` 出来的 `params` 与 `appliedRules` 固定在结果上方，永远可见；任何「参数来自默认值」的字段标琥珀。
4. **12 型「不适用」卡复验**：每型一句专属原因（不是同一句复制），点「去例题页」能真的到 `/t/<id>`。
5. **D1–D3 决策（二选一，写进 about）**：要么接 live 重算，要么明确写「这三型是快照管线，改参数不重算」并在页面标住。**不许含糊过去。**
6. **撤销上限与语义**：`Ctrl+Z` 之外，界面要有可点的撤销/重做（已有 `↶ ↷`），且「撤销后 appliedRules 与 params 一起回退」写进 tooltip。

**R2 验收**：新增 `check:labnav`（首页三栏 → 每栏至少一个入口可达、digital 可达、不适用卡文案两两不同）；`check:assemble` 增参数实验重算断言；三张截图（lab 首页、重算前后、不适用卡）。

### R3-T1 · 改过结构的 BJT/MOS 图也要出等效电路（研究项，2–3 天）

这是「自己装配」真正的最后一公里：用户把 Rc 删了、Rl 挪了，我们仍要能指着中间那块说「这是 π 模型」。

- 做法（纯代数，不碰 AI）：对三端器件做**端口小信号参数提取**——在通用 MNA 解上施加端口测试源，求 `y11/y12/y21/y22`，换算成 `gm / ro / rπ`（BJT）或 `gm / ro`（MOS），再用现成的 `bjtPiLayout` / `mosLayout` 画等效图。
- 判据：提取值与归约参数**逐位相同（≤1e-9）**；三条测试源各自残差都要报出来。
- 门禁 `check:equiv-extract`：① A3 骨架不动 → 提取值与模板 `gm/rπ/ro` 一致 ② A3 删 Rc → 提取值不变（管子没变），等效图仍画得出 ③ 把 gm 改 1% → 提取值必须跟着变（证明有分辨率）④ 变异：漏掉一个端口测试源 → 红。
- 做不到就明说：器件不是三端、或端口找不全 → 不画等效图，写「这张图认不出晶体管」。
