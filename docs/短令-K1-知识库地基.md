## 1. 类型（`src/kb/types.ts`，照抄）

```ts
export type Subject = 'circuit' | 'digital' | 'mechanics' | 'statics';

export type KbFigure =
  | { kind: 'photo'; src: string; alt: string; caption: string; credit: string }
  | { kind: 'svg';   src: string; alt: string; caption: string }
  | { kind: 'live';  templateId: string; params?: Record<string, number>; caption: string };

export interface KnowledgeEntry {
  id: string;                 // 'mechanics.bending-moment'
  subject: Subject;
  chapter: string;
  title: string;
  aliases: string[];          // ≥2
  oneLine: string;            // ≤40 字
  approach: string[];         // 3–6 步，动词开头，每步 ≤48 字
  formulas: { tex: string; note?: string }[];
  points: string[];           // 3–6 条，每条 ≤48 字
  pitfalls?: string[];        // 0–3 条
  figures?: KbFigure[];       // 0–3 张
  solvable?: { templateId: string };
  related?: string[];
  source?: string;            // 只写章节
}
```

## 2. 52 条空位（`src/kb/entries/{circuit,digital,mechanics,statics}.ts`）

来源：`docs/覆盖账本-四科题型.md`。脚本 `scripts/build-kb-skeleton.mjs` **只在新文件不存在时写**，绝不覆盖已有文案；每条只填机器字段：

- `id / subject / chapter / title / aliases / oneLine`
- `approach: []`、`points: []`（空 = 门禁 ② 红，这就是进度表）
- `solvable`：29 条能算的填 `{ templateId }`（映射取自 `docs/覆盖账本-四科题型.md` 的「对应模板」列）
- 其余 23 条不填 `solvable`

数量核对：circuit 15 / digital 11 / mechanics 14 / statics 12 = **52**。

## 3. 索引（`src/kb/index.ts`，构建期生成，纯数据）

```ts
import { CIRCUIT } from './entries/circuit';   // …四科
export const KB: KnowledgeEntry[] = [...];

export const KB_INDEX: { term: string; ids: string[] }[];   // 倒排，term 小写
```

- 分词：CJK 二/三字滑窗 + 拉丁 `[a-z0-9]+`，全部小写；不引第三方库。
- 索引体积目标 < 120 KB（52 条量级足够）；`check:kb` 加一条上限断言，超了报「索引过大，先看分词」。

## 4. 意图分流（`src/kb/intent.ts`）

```ts
export type Intent = 'problem' | 'concept';
export function detectIntent(text: string): Intent;
export const INTENT_CASES: { text: string; want: Intent }[];   // 20 条
```

判 `problem`：≥2 个「数值+单位」（`12kN` `2m` `100Ω` `1mS` 都算）或出现祈使动词（求/计算/校核/画出/确定）。
否则 `concept`。**只做分流，不做识别**；错字容错不在这里做。
