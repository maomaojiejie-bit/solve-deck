## A1. 修四处排版缺陷

四个组态的**拓扑已经全对**，不要动接线、不要动坐标链路，只动标签与文案：

1. **注释被地符号穿过**（CB/CC/CG/CD 四张 + 默认的 CE/CS 也有）
   `t-note` 用 `side='up'` 的居中锚点，x 与接地符号同列（都在 340），地符号的竖杆和横杠从文字中间穿过去。
   - 改：`b.text('t-note', [560, 512], '…', 'left')`，或把 `groundRail` 的 `gndAt` 挪到轨道最右端。
   - 定规矩写进 `docs/电路接线守则.md`：**`t-note` 一律放 `y ≥ GND_Y + 44` 的独占行，且 x 区间不得覆盖任何 gnd 的 x 区间。**

2. **「B 交流地」/「G 交流地」贴着 Rc/Rd 标签**（CB、CG 各一处，中间没有空隙）
   - 给 `acBar(b, id, x, y, text, side?)` 加第 6 个参数 `side: 'right' | 'left' = 'right'`，CB/CG 传 `'left'`；
   - 或把 Rc/Rd 那一列右移 60。选一个，别两边都动。

3. **CG 的 MOS 在 `rot=90` 下认不出是 MOSFET**（唯一算严重的）
   - 现象：D/S 的斜引线竖起来、bulk 短桩 `M34 50H40` 也竖起来、箭头横躺，三样绞成一团。
   - 推荐做法：在 `scripts/gen-symbol-art.mjs` 的 MAP 里加 `'nmos-rot90'` 条目 —— `drop: ['bulk']`，用 `extra` 把 D/S 改成直角折线（例：`M34 34 V10 H60`、`M34 66 V90 H60`），
     `src/render/symbols.ts` 里给这个 kind 声明与 rot=0 版一致的引脚语义（g 在上、d 右上、s 右下）。
   - 备选：CG 不改朝向，器件保持 rot=0，栅极横杠画在器件左侧，输入从源极下方绕上来。
   - **不管选哪个，CD 那张也要跟着统一**（现在 CD 的 MOS 上还有个 `⊣` 形状的短桩，看着像污点）。

4. **CC 写成「c 交流地（cc）」** —— 小写 c，其它三张是 `B 交流地`、`G 交流地`，注释里也说「C 直接交流地」。
   - 统一成「C 交流地（CC）」，横杠标签一律大写。

# 批次 B · P5-a 导出 PDF + about 页（等我说继续）

## B1. 导出：走打印路径，不要引新依赖

硬约束：`check:runtime` 要求 App 路由闭包内没有 `node:*`；`check:license` 检查依赖许可证。
**首选零依赖方案**：加一套 `@media print` 样式 + 一个「导出 PDF」按钮调 `window.print()`
（浏览器打印对话框里选「另存为 PDF」）。

要做的：

1. **深色主题必须转浅色**。现在打印会得到白纸黑字全黑底 —— 用 `@media print` 覆盖 `tokens.css` 的颜色令牌
   （背景 `#fff`、正文 `#111`、线 `#333`、高亮保留但降饱和），并加 `-webkit-print-color-adjust: exact` 只在必要处。
2. **一页 A4 竖排放下**：题目（模板标题 + 已知量表）→ 五个步骤（公式 KaTeX 保持可打印）→ 主图 + 等效图 →
   结果表 → 六项校验。`@page { size: A4; margin: 14mm; }`；超长时允许分页，但不许横向截断。
3. **图上不要留深色画布**：`AnalogSchematic` 的 SVG 里凡是填底色/网格的，打印时去掉网格、保留轴线与器件。
4. 页眉页脚：作品名 + 模板 id + 生成时间（`#/t/A3` 这种可复现信息，便于评审对照）。
5. 按钮放右栏结果区顶部，文案「导出 PDF」；窄屏收进一个 `⋯` 菜单里。

**加分项（做不完可以不做）**：长图 PNG 需要 canvas 栅格化字体，成本高，先别碰。

## B2. about 页（比赛要的「过程」在这里）

新增路由 `#/about`，一张单页，内容五块：

3. **不许调参数换绿**（改容差、改阈值、改断言范围都算）。
4. 改 `src/examples/*.json`、改布局、改符号资产之后，**必须重建快照**再跑门禁，否则门禁读旧快照给假绿。

   （会把 UTF-8 中文整篇转成乱码，本仓库已经踩过两次）。
6. 截图脚本必须**先断言**（`result.config`、晶体管 `rot`、`render_specs` 里有 `main` 与 `pi`）再截图，
   并且每张图用独立 `--user-data-dir`。
