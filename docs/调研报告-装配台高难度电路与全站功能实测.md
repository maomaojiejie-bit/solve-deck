## 2. 问题清单

### F1 · medium · 连线第二端点候选被硬截断为 8 个
- 位置：`src/pages/Lab.tsx:2641` `const candidates = anchors.filter((a) => a.key !== first).slice(0, 8);`
- 实测：面板第二端点按钮 DOM 计数**恰为 8**。两个锚点都排在第 9 位之后的引脚对，无法经面板连线。
- 影响：多元件 / 复合器件展开后锚点数远超 8，部分合法连线在 UI 上不可达。
- 复现：展开两个复合器件 + 加器件使锚点 >9，点第一端点后数第二端点按钮。

### F2 · high · addDevice  id 碰撞（同名守卫是死代码）
- 位置：`src/core/lab/ops.ts:485-491`。守卫 `if (nodes.some((n) => n.id === op.label))` 比较的是 `op.label`（如 `R`），但实际创建 id 为 `` `n-add-${op.label}` ``（`n-add-R`）。两者永不相等 → 守卫永不触发。
- 实测：连加两个同类器件产生重复 id `n-add-R` / `n-add-C`；DOM 出现重复 `data-pin` 选择器（bsk 报「selector matched 2 elements」）；URL `?g=` 解码后含两个 `n-add-R` 节点。生产 bundle `query-Cmsn8q8A.js` 含同一死守卫（`i.some(e=>e.id===n.label)` + `n-add-${n.label}`）。
- 影响：重复 id 是 F4 / F5 的根源。
- 复现：装配台连点「+R」两次，解码 URL 图或查 DOM `data-pin`。

### F3 · high · 导线 id 用 `edges.length` 生成，删除后复用
- 位置：`src/core/lab/ops.ts:536` ``{ id: `e-pin-${edges.length}`, … }``。
- 实测：高难度电路解码图 `graph3.json` 中 `e-pin-15`、`e-pin-16`、`e-pin-17` **各出现 2 次**（19 条边里 3 对重复）。删除导线使 `edges.length` 回落，新线复用旧 id。
- 影响：重复 edge id → React key 冲突（F5）、删线 / 选中误伤。
- 复现：连若干线→删几条→再连，解码 URL 图统计 edge id。

### F4 · high · 删除按 id 过滤，一次删掉所有同 id 节点
- 位置：`src/core/lab/ops.ts:406` `next.nodes = nodes.filter((n) => n.id !== op.nodeId && …)`。
- 实测：存在两个同 id 电容时，点一次「删」把**两个都删掉**（解码图前后对比）。
- 影响：与 F2 叠加造成误删、数据丢失。
- 复现：先造重复 id（F2），再删其中一个。

### F5 · high · 重复 React key 导致 reconciliation 损坏（生产静默）
- 位置：`src/pages/Lab.tsx:1014,1381` `key={row.id}`；`:1422` `key={device.id}`；`:1602,2910` `key={edge.id}`；`:1923` `key={pin.key}`。
- 实测：重复 id 状态下点「恢复骨架」，badge 已回「骨架」、URL 已清，但列表仍残留幻影器件行 / 引脚 / 规则；**只有整文档 reload 才清干净**。hash 路由跳转不 remount Lab，故无效。
- 影响：UI 与真实图不一致，学生看到不存在的器件 / 连线；生产构建无 console 警告（console.out errors=0），问题静默。
- 复现：造重复 id（F2/F3）→恢复骨架→观察残留→硬刷新对比。

### F6 · high · 内置「并联电阻对」拓扑不是并联
- 位置：`src/core/lab/compositeBuiltin.ts` `cmp-parallel`（约 :40-62）。note 声称「R3 ∥ R4：Req = R3·R4/(R3+R4)」，端口 A=R3:a、B=R4:b，但 `inner.edges` **只有一条** `e-par: R3→R4`（且 points 为退化 `[[0,0],[0,0]]`）。
- 分析：并联需要把 R3:a↔R4:a、R3:b↔R4:b 两对节点分别 joined（两条导线）；单条导线只能构成串联（或此处的退化短杠 / 不连接）。实测 inner 边数 = 1。
- 影响：模块标称 Req=10k（20k∥20k），实际端口间为串联 40k 或不连通；物理语义错误。
- 说明（诚实）：高难度电路整图求解时该对被几何并网混淆（见 F9），**未**单独干净测得该模块端口 Req；本条为结构 / 代码级判定。
- 复现：读 `cmp-parallel.inner.edges`；或单独载入该模块测端口等效电阻。

### F7 · medium · 引脚热区重叠，轨 / 总线端点点不中
- 实测：点 `e-gnd-rail:from` / `:to` 报「pointer target is covered or unavailable」；改连同一电气结点 `n-gnd:t` 才成功。
- 影响：密集轨 / 总线上的引脚在 UI 上不可点，连线被迫绕路。
- 复现：骨架 A3 点接地轨两端引脚。

### F8 · medium-high · 展开复合器件的行名按钮宽度 0 → 行不可选 → 语义不可标
- 实测（`bsk evaluate` 量宽度）：`dev-row-cmp/cmp-divider/R1` 子元素 = SPAN 119 / **BUTTON 0**（"R 30k"）/ SPAN 91 / 旋转 19 / 种类 62 / 收拢 30 / 删 20；`cmp/cmp-parallel/R3` 同。列宽 316px 溢出，flex 把名按钮压到 0。
- 后果：名按钮不可点（bsk「no content quads / no visible area」）→ 行选不中 → 语义 `<select>` 只在该行选中时渲染（`Lab.tsx:1468-1484`）→ **bias 等标签标不上 → 等效图不渲染 / 求解被 gate**。本次被迫把 bias 标到可达的 `n-add-R`(Re) 上绕开。
- 对照：骨架行名按钮宽度正常（obs43），故 F8 特指展开复合器件行。
- 复现：展开分压器 / 并联对，量行内 BUTTON 宽度。

### F9 · high · 加元件提高难度后，答案 / 讲解 / 等效电路管线退化
- 实测（高难度电路：18 节点 19 边，含分压器 + 并联对 + 耦合电容 + Re）：求解落「这张图与骨架不一致：讲解稿对不上，按图求解」→ 通用 MNA；结果 **Av = V(e-pin-18#0)/V(e-in#2) = 0**，Q 小信号 VBE=VCE=IC=0，除 1V 测试源外全节点 0V，**Ri/Ro「这一版不给」**，无 π 模型等效图、无分步讲解（obs40.txt、05-solve-degenerate.png）。
- 根因（代码 + 实测）：
  1. 电容直流开路：`src/core/lab/netSolve.ts:342-344` `case 'cap': break;`（不 stamp）。但结果却标「小信号增量 / 电压增益」。对**电容耦合**放大器，耦合电容在交流小信号下应视为短路；按开路算则输入到不了基极 → Av=0。模型口径自相矛盾。
  2. 输出网自动选择落到接地网：`src/core/lab/measures.ts:614-622` 取晶体管 c 脚网，认不出取 |v| 最大非地网；本次报 `e-pin-18#0`（Re 底→地，0V）。
  3. 几何并网脆弱：`netSolve.ts buildNets` 用 `touchesPolyline`（TOL=0.6）把折线碰到的点并成一个网；导线横穿器件_body_ 时会误并（本次 n-rs:b→Cc:a 的横线穿过 R3/R4 body）。
- 对照（同页骨架）：A3 骨架 F 档、Av=-45.537 / Ri=2600 / Ro=1960.8、π 模型渲染（obs46）。**即「骨架对、加料错」**。
- 影响：装配台「改结构再算」的核心价值在多元件场景失效；学生拿到全 0 退化解且无讲解。
- 复现：按 graph3.json 搭图→标语义→确认 7 参→分步求解。

### F10 · medium · 电容在 A3 白名单外，但装配台允许加
- 实测：归约预览 / 求解警告「白名单外器件「C 10µF」：本题型不支持；请删除它，或换成电阻 / 电源等骨架内器件，或改题型」。
- 矛盾：真实共射放大器**必须**有耦合 / 旁路电容；装配台「+C」可加，但 A3 求解器拒收。加 C 既被警告、又因 F9(1) 被开路 → 双重不可用。
- 影响：题型白名单与装配白名单不一致，学生加「物理上必需」的元件反而被拒。
- 复现：A3 加「+C」→求解看警告。

### F11 · medium · 参数滑杆 aria 值为归一化 0–1000，读屏念错数
- 实测：β slider `="286"`（真值 100）、Ic `="500"`（0.001）、Rc `="434"`（2000）、Rl `="667"`（10000）、Rs/Re `="333"`、VA `="444"`（obs40.txt）。
- 影响：屏幕阅读器把 β 念成「286」而非「100」；aria-valuenow 未映射到工程值 / 未带 aria-valuetext。
- 复现：读参数实验场 slider 的 aria-valuenow 与旁边真值对比。
