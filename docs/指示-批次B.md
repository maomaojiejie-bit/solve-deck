## B1 · 回补 MOS 的极性箭头（最重要的语义修复）

### 现状

`docs/shots/A5-CG.png` 和 `A5-CD.png` 里两根管子**都没有任何极性标记**，
于是 NMOS 与 PMOS 在当前渲染下**长得一模一样**。这是信息丢失，不是审美问题。

原因是我上一次的说法有歧义（「丢掉衬底桩和横躺箭头」），被理解成「不要箭头」。
真实要求是「**箭头不要躺着，但必须在**」。

### 要做

1. **`nmos` / `pmos`（竖放，rot=0）恢复箭头**
   资产里本来就有（`nmos.svg` 的 `arrow`），只是被 `drop:['arrow']` 之类去掉了。
   竖放时箭头在源极引线上、**指向沟道**（N 沟道向里、P 沟道向外）。

2. **新增 `pmos-r90`（横放）与 `nmos-r90` 配对**
   现在只有 `nmos-r90`，横放这条路只打通了一半。`pmos-r90` 与 `nmos-r90` 镜像：
   引脚语义对齐（`g(0,-50) d(50,10) s(-50,10)` 这套），**箭头横着画、指向沟道**，
   N 向内 / P 向外。

3. **`src/render/symbols.ts` 里四个 kind 都要有**
   `nmos` / `nmos-r90` / `pmos` / `pmos-r90`，引脚语义与现有 `nmos` / `nmos-r90` 一致。

4. **加一条断言（S16）：带极性器件必须有极性笔画**
   `check:schematic.mjs` 里加 S16：对 spec 中出现的每个 MOS/BJT kind，
   检查 `SYMBOL_ART[kind].inner`（或 `artOverlay`）里存在箭头笔画；
   匹配用**固定坐标串**（例：`M40 50L46 46` 这类），不要用宽松正则。
   断言风格与前 15 条一致。

   **必须做变异测试**：把箭头从 `nmos.svg` 删掉 → 门禁必须 exit≠0 并指名是哪个 kind；
   再还原 → 回绿。

5. **改完重建快照**（`A3.json / A3-CB / A3-CC / A5.json / A5-CG / A5-CD` 六份都受影响），
   再重拍 `docs/shots/` 四张图，并更新守则 §十二：
   「极性箭头规则：N 向内 / P 向外；竖放竖画、横放横画；不许为了好看删极性标记」。

## B2 · 导出 PDF：走打印路径，零新依赖

### 硬约束

`check:runtime` 要求 App 路由闭包内无 `node:*`；`check:license` 查许可证。
所以**不要引 html2canvas / jsPDF**，走浏览器自带打印。

### 要做

1. **`@media print` 浅色令牌**（这是最容易翻车的一处）
   现在深色主题直接打印会得到**整张黑纸**。在 `src/ui/tokens.css` 里补一套打印覆盖：
   背景 `#fff`、正文 `#111`、次级文字 `#555`、线 `#333`，高亮保留但降饱和；
   只在必要处用 `print-color-adjust: exact`。

2. **`@page { size: A4; margin: 14mm; }`**，一页内按这个顺序放下：
   **题目（模板标题 + 已知量表）→ 五个步骤（KaTeX 公式保持可打印）→ 主图 + 等效图 → 结果表 → 六项校验**。
   超长允许分页，但**不许横向截断**（图用 `max-width:100%`、SVG `preserveAspectRatio` 保持）。

3. **打印时去掉画布装饰**：深色底、网格、光晕一律不打印，保留轴线、器件、导线、标签。

4. **页眉/页脚**：作品名 + `模板id`（如 `A3-CB`）+ 生成时间（`YYYY-MM-DD HH:mm`），便于评审对照。

5. **按钮**：结果栏顶部加「导出 PDF」，`onClick` 调 `window.print()`；
   窄屏收进 `⋯` 菜单。打印样式里要把按钮、侧栏、底部步骤条全部 `display:none`。

6. 打印时**隐藏交互控件**：步进按钮、倍速、`⋯` 菜单、返回按钮。

## B3 · about 页：把「过程」讲清楚

新增路由 `#/about`（`#/` 页脚加「关于」入口，`Result` 页脚也加一个），单页五块：

1. **一句话**
   这是什么 + 谁在什么场景下用：
   「工科在读生做作业/复习时，把一道题拆成 5 步、每步配一张图、并给出 6 项自校验的拆解台。」

2. **怎么用（5 步以内，编号列表）**
   进首页选题 → 点左侧步骤看联动 → 切到组态变体对比 → 看右侧六项校验 → 导出 PDF。

3. **覆盖表**
   | 科目 | 题目 | 组态变体 |
   | --- | --- | --- |
   | 模拟电路 | A1–A7（7 题） | A3：CE/CB/CC、A5：CS/CG/CD |

4. **做出来的过程**
   时间线 + 8 个节点，每节点一句「解决了什么」+ 一张截图位（直接引 `docs/shots/` 里的图，
   路径用 `/shots/xxx.png` 这种静态资源引用）。节点建议：
   符号表统一 → 积木式装配 → π 模型与原图并排 → 六项校验 → 八道门禁 →
   变异测试 → 四组态收口 → 极性箭头。

5. **技术与边界（这块最加分，别省）**
   - 纯前端静态站，无后端、无网络请求、无账号；
   - 只解**静定/可解析**题型：小信号（CE/CB/CC、CS/CG/CD）、组合逻辑、卡诺图；
   - **不做**：非静定结构、时序仿真、稳定性/大信号失真、任意网表；
   - 每个结论都带「六项校验」结果，校验不过就不给结论。
